# 802.1X Port-Based Authentication

## Overview

The SDN policy engine implements IEEE 802.1X-style port-based network access control
using certificate-based authentication. Instead of traditional EAP/RADIUS, devices
authenticate using IDevID certificates issued through ACME enrollment.

## Port State Machine

The policy engine manages port authentication through a defined state machine:

```
┌────────────────────────────────────────────────────────────────────────┐
│   Unconnected    │  Port not registered, no device                     │
└────────┬─────────┴─────────────────────────────────────────────────────┘
         │
         │ RegisterPort(mac, portID)
         ▼
┌────────┴───────────────────────────────────────────────────────────────┐
│   Provisioning   │  VLAN 998, limited access                           │
│                  │  Allowed: DHCP, DNS, HTTPS to platform              │
└────────┬─────────┴─────────────────────────────────────────────────────┘
         │
         │ OnEnrollmentComplete(cert)
         ▼
┌────────┴───────────────────────────────────────────────────────────────┐
│    Enrolled      │  Still VLAN 998                                     │
│                  │  Awaiting client activation                         │
└────────┬─────────┴─────────────────────────────────────────────────────┘
         │
         │ ActivateDevice(serial)
         ▼
┌────────┴───────────────────────────────────────────────────────────────┐
│   Authorized     │  Production VLAN from profile                       │
│                  │  Full ACL-based access                              │
└────────┬─────────┴─────────────────────────────────────────────────────┘
         │
         │ Certificate expires / compliance issue
         ▼
┌────────┴───────────────────────────────────────────────────────────────┐
│  Quarantined     │  quarantine zone (default VLAN 202), isolated       │
│                  │  Access to remediation only                         │
└────────┬─────────┴─────────────────────────────────────────────────────┘
         │
         │ Certificate revoked
         ▼
┌────────┴───────────────────────────────────────────────────────────────┐
│    Blocked       │  DROP all traffic                                   │
│                  │  Admin intervention required                        │
└────────────────────────────────────────────────────────────────────────┘
```

## Certificate-Based Policies

### Policy Extraction

The policy engine extracts network policies from X.509 certificates:

```go
// PolicyExtractor interface
type PolicyExtractor interface {
    ExtractPolicy(cert *x509.Certificate) (*PortPolicy, error)
    ExtractTenantID(cert *x509.Certificate) (string, error)
    ExtractVLAN(cert *x509.Certificate) (uint16, error)
    ExtractACLs(cert *x509.Certificate) ([]ACLRule, error)
}

// Default implementation uses certificate fields:
// - TenantID: Subject.Organization[0]
// - VLAN: From device profile lookup
// - ACLs: From device profile configuration
```

### Certificate Fields Used

| Field | Policy Attribute | Example |
|-------|------------------|---------|
| Subject.Organization | Tenant ID | "Acme Corp" |
| Subject.SerialNumber | Device Serial | "SN123456" |
| NotAfter | Policy Expiration | 2026-01-01 |
| Extensions | Custom policies | VLAN, rate limits |

### Policy Structure

```go
type PortPolicy struct {
    // TenantID from certificate organization
    TenantID string

    // VLAN from profile or certificate extension
    VLAN uint16

    // ACL rules from profile
    ACLs []ACLRule

    // The authenticating certificate
    Certificate *x509.Certificate

    // Expiration time
    ExpiresAt time.Time

    // Metadata for logging/auditing
    Metadata map[string]string
}

type ACLRule struct {
    Priority    int
    Match       FlowMatch
    Action      FlowAction
    Description string
}
```

## Enrollment Integration

### SDN Enrollment Hook

The enrollment hook integrates with the ACME server to handle certificate issuance:

```go
import "github.com/jeremyhahn/go-trusted-platform/pkg/sdn/policy"

// Create enrollment hook
config := policy.SDNEnrollmentHookConfig{
    Logger:       logger,
    PolicyEngine: policyEngine,
    ProfileDAO:   profileDAO,
}

hook, err := policy.NewSDNEnrollmentHook(config)

// Register with ACME server
acmeServer.RegisterOrderFinalizeHook(hook.OnEnrollmentComplete)
```

### Enrollment Event

```go
type EnrollmentEvent struct {
    // Request context
    Context context.Context

    // Issued certificate
    Certificate *x509.Certificate

    // Client IP (for ARP lookup)
    ClientIP string

    // TCG-CSR-IDEVID specific fields
    IsTCGCSR      bool
    ProductModel  string
    ProductSerial string

    // Device permanent identifier
    PermanentIdentifier string
}
```

### Enrollment Flow

1. **Device connects** - Port registered in Provisioning state (VLAN 998)
2. **ACME enrollment** - Device obtains IDevID certificate
3. **Hook triggered** - OnEnrollmentComplete called with certificate
4. **Profile lookup** - Find device profile by serial or MAC
5. **State transition** - Port moves to Enrolled state
6. **Client activation** - Device calls /api/v1/device/activate
7. **Policy applied** - Production VLAN and ACLs installed

## State Transitions

### Valid Transitions

| From | To | Trigger |
|------|----|---------|
| Unconnected | Provisioning | Port registration |
| Provisioning | Enrolled | Enrollment complete |
| Provisioning | Authenticating | Direct authentication |
| Enrolled | Authorized | Client activation |
| Authorized | Quarantined | Certificate expired |
| Authorized | Quarantined | Compliance failure |
| Quarantined | Authorized | Remediation complete |
| Quarantined | Blocked | Certificate revoked |
| Any | Blocked | Certificate revoked |

### Transition Handlers

```go
// Set port state directly
err := engine.SetPortState("eth1", policy.PortStateProvisioning)

// Apply policy (transitions through authenticating to authorized)
err := engine.ApplyPolicy("eth1", portPolicy)

// Block port (installs DROP flows)
err := engine.BlockPort("eth1")

// Unblock port (removes DROP flows, returns to provisioning)
err := engine.UnblockPort("eth1")
```

## Policy Engine API

### Port Management

```go
// Get current port state
state, err := engine.GetPortState("eth1")

// Get detailed port info
info, err := engine.GetPortInfo("eth1")
// Returns: PortID, State, Policy, LastStateChange, AuthAttempts, ErrorCount

// Get current policy
policy, err := engine.GetPolicy("eth1")
```

### VLAN Management

```go
// Set port VLAN directly
err := engine.SetPortVLAN("eth1", 100)

// Get port VLAN (from policy)
vlan, err := engine.GetPortVLAN("eth1")
```

### Certificate Authentication

```go
// Authenticate port with certificate
err := engine.AuthenticatePort("eth1", certificate)

// Handle certificate expiry
err := engine.OnCertificateExpired("eth1")

// Handle certificate revocation
err := engine.OnCertificateRevoked("eth1")
```

## Flow Rules Generated

### Provisioning State

```
# DHCP
priority=100,udp,tp_dst=67,actions=normal
priority=100,udp,tp_dst=68,actions=normal

# DNS
priority=100,udp,tp_dst=53,actions=normal
priority=100,tcp,tp_dst=53,actions=normal

# Platform HTTPS
priority=100,tcp,tp_dst=443,actions=normal
priority=100,tcp,tp_dst=8443,actions=normal

# Default drop
priority=0,actions=drop
```

### Authorized State

```
# VLAN assignment (via OVSDB, not flow)
# Port tag set to profile zone VLAN (e.g. trusted = 200)

# ACL rules from policy (example)
priority=1000,tcp,tp_dst=443,actions=normal
priority=1000,tcp,tp_dst=80,actions=normal
priority=500,icmp,actions=normal

# Default deny
priority=1,actions=drop
```

### Blocked State

```
# High priority drop for all traffic
priority=65000,in_port=<port>,actions=drop

# Additionally, OVSDB sets admin_state=down
```

## Certificate Monitoring

### Enable Monitoring

```go
config := policy.Config{
    EnableMonitoring: true,
    MonitorConfig: policy.MonitorConfig{
        CheckInterval:   time.Hour,
        ExpiryThreshold: 7 * 24 * time.Hour, // 7 days
    },
}

engine, err := policy.NewEngine(config)

// Get monitor for callbacks
monitor := engine.GetMonitor()
monitor.Start()
defer monitor.Stop()
```

### Expiry Handling

When certificates expire:
1. Monitor detects expiration
2. OnCertificateExpired called
3. Port transitioned to Quarantined
4. Quarantine VLAN (666) applied
5. Remediation flows installed

## Integration with Compute

The compute orchestrator integrates with SDN policy for VM network access:

```go
// Configure orchestrator with policy engine
config := &compute.OrchestratorConfig{
    PortAuthEnabled: true,
    PolicyEngine:    policyEngine,
}

orchestrator, err := compute.NewQEMUOrchestrator(config, logger)

// When VM network is attached, port enters provisioning
err = orchestrator.AttachNetwork(ctx, instanceID, "eth0")

// After enrollment, activate the instance
err = orchestrator.ActivateInstance(ctx, instanceID, productionPolicy)
```

See [802.1X Network Attachment](../compute/802.1X-network-attachment.md) for details.

## Security Considerations

1. **Certificate Validation** - All certificates validated before policy extraction
2. **Revocation Checking** - CRL/OCSP validation for issued certificates
3. **Expiry Enforcement** - Automatic quarantine on certificate expiry
4. **VLAN Isolation** - Provisioning and quarantine VLANs are isolated
5. **Defense in Depth** - Both OpenFlow DROP and OVSDB admin_state for blocking
6. **Audit Logging** - All state transitions logged with timestamps
7. **Rate Limiting** - Authentication attempt limits per port

## Troubleshooting

### Port Stuck in Provisioning

```bash
# Check port state
platformctl sdn port state eth1 --bridge br0

# Verify enrollment completed
journalctl -u trusted-platform | grep "enrollment complete"

# Check ARP table for MAC
cat /proc/net/arp | grep <ip>
```

### Certificate Not Accepted

```bash
# Verify certificate validity
openssl x509 -in cert.pem -noout -dates

# Check certificate chain
openssl verify -CAfile ca.pem cert.pem

# View certificate details
openssl x509 -in cert.pem -noout -text
```

### Flows Not Applied

```bash
# Check OpenFlow flows
ovs-ofctl dump-flows br0 | grep <port>

# Verify port VLAN
ovs-vsctl get port eth1 tag

# Check bridge configuration
ovs-vsctl show
```
