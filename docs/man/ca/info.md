# NAME

**ca info** - Displays Certificate Authority information

# SYNOPSIS

**ca info** [*OPTIONS*] [*ARGUMENT*]

# DESCRIPTION

**ca info** - Displays key store, certificate store, and general information
about a Certificate Authority.

## References
