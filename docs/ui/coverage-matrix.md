## How to read this file

- **REST**: the route whose handler name matches the operation, as `METHOD path`. The path is relative to the area's mount in the REST router (for example `/users` in the IAM router). `-` means no route with a matching handler was found.
- **Web page**: the page under `web/src/app` (route groups kept) that calls the operation through the TypeScript SDK (`sdk/javascript/src/services`), directly or through a feature component it imports. A page marked `(read-only)` shows the resource but does not perform this write.
- **platformctl**: the view in `cmd/platformctl/frontend/src` that performs the operation through the desktop daemon binding.
- **Playwright spec**: the file under `web/e2e` that navigates to the page.
- **Status**:
  - `covered`: a page performs the operation and a spec visits that page;
  - `partial`: a page (or platformctl view) performs it but no spec visits the page, or the only page for the resource is read-only for this write;
  - `missing`: no page and no platformctl view performs it;
  - `not-UI: reason`: daemon-internal, host-local, streaming plumbing or agent-to-agent operation;
  - `blocked: integration`: served by the composed go-quicbaas data plane (cache, messaging, object storage, scheduler); out of scope for the epic.
- The matrix was generated by script (proto parse, route registrations, SDK method paths, page imports, spec `goto` targets) and spot-checked by hand; see "Method and limits" at the end.
