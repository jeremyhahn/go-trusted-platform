# Plan: unit tests for the iam dashboard pages, part 3 (#1843)

UI epic #1665 support. Web only; no Go change.

## Objective

Give each of these modules a test file beside it that covers every export,
including edge, error and invalid inputs, with network calls mocked:

- `web/src/app/(dashboard)/iam/roles/page.tsx`
- `web/src/app/(dashboard)/iam/tokens/page.tsx`
- `web/src/app/(dashboard)/iam/users/[id]/page.tsx`
- `web/src/app/(dashboard)/iam/users/page.tsx`

## Approach

Follow `web/src/app/(dashboard)/tenant/invitations/page.test.tsx`: vitest and
@testing-library, `@/hooks` and `@/contexts/AuthContext` mocked with
`importOriginal`. The data table, its column header and its row-action menu
are replaced by thin inline renderers so the page's own columns, cells,
actions and bulk actions are driven directly in jsdom.

## Slices (one commit each)

1. `iam/roles/page.test.tsx`: auth loading, missing tenant, load error and
   retry, the fetcher with and without a tenant, the onError toast, the role
   mapping (name and description fallbacks, permission counts, stats), view,
   edit, row click and add navigation, single delete (confirm, cancel,
   failure) and bulk delete (confirm, cancel, partial failure).
2. `iam/tokens/page.test.tsx`: the same states, the app mapping, grant-type
   badges and created column, register dialog (empty name rejected, trimmed
   name sent, secret shown, failure), rotate secret, delete, bulk delete and
   copying the secret.
3. `iam/users/[id]/page.test.tsx`: `generateStaticParams` placeholder and
   `Page` rendering the mocked client component.
4. `iam/users/page.test.tsx`: the list page's states, mapping and actions.

## Out of scope

- Changes to the modules themselves, unless a test exposes a real bug (then
  a separate `fix(web)` commit after the test commit).
- The client component `user-detail-client.tsx` (not re-tested).
- Web lint (ungated, #419).
- Branches the page cannot reach (the mutations' and bulk delete's own
  missing-tenant checks: the page returns early without a tenant).
