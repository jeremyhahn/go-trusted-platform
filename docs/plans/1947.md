# #1947: daemon service-control RPCs over the SDK REST transport

## Objective

The Go SDK's REST transport maps the five PlatformDaemon service RPCs
(ListServices, GetServiceStatus, StartService, StopService, RestartService)
to the daemon's REST routes. It keeps the gRPC service's answers, codes
included (docs/SPEC.md, docs/sdk/architecture.md §2).

## Slices

1. Routes, encoders and decoders for the five RPCs
   (sdk/go/transport/rest/daemon_services.go), with round-trip tests against
   the daemon REST handlers.
2. 409s keep the gRPC code (Codex review P1 on PR #1952):
   `translateInvokeError` takes the gRPC method and asks `restConflictCodes`
   first. StopService and RestartService 409s are FailedPrecondition;
   a StartService 409 is AlreadyExists only for the daemon's
   already-running refusal, FailedPrecondition otherwise.
   Test: TestDaemonServices_ConflictKeepsTheGRPCCode.

## Out of scope

- Daemon handler changes in pkg/api/daemon.
- go.mod / go.sum and CI workflows.
