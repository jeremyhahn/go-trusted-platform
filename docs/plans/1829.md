# Plan: #1829 unit tests for the attestation dashboard pages

Part of the UI epic #1665.

## Objective

Five attestation dashboard modules in `web/src/app/(dashboard)/attestation/`
have no unit test. Test every export of each, including edge, error and
invalid inputs. Change no module unless a test exposes a real bug.

## Slices (in order, one commit each)

1. `[id]/page.test.tsx`: `generateStaticParams` returns the placeholder id;
   `Page` hands its params promise unchanged to the detail client (resolved,
   empty id, rejected).
2. `eventlogs/page.test.tsx`: `EventLogsPage` loading, list, empty, service
   error and filter behaviour.
3. `manifests/page.test.tsx`: `ManifestsPage` list, empty, error and actions.
4. `quotes/page.test.tsx`: `QuotesPage` list, empty, error and actions.
5. `verify/page.test.tsx`: `VerifyPage` valid, invalid and failing
   verification input.

Each test mocks `@/hooks` (`useAttestation`, `useToast`) the way
`attestation/page.test.tsx` does.

## Gates

`npm run test:unit`, `npm run typecheck`, `npm run lint` in `web`.

## Out of scope

- `attestation-detail-client.tsx` and the overview page (already tested or
  handled elsewhere).
- Go code, e2e (Playwright) tests.
