# Plan: #966 no test sleeps

Objective: no test at any tier sleeps. Every sleep becomes a bounded
polling helper or a wait on what the page renders or a mock records.

## Slices

1. Go and shell test sleeps (earlier slice of the row).
2. Playwright sleeps in `web/e2e/dashboard.spec.ts` (this slice):
   - refresh test: `waitForTimeout(500)` + count check becomes
     `expect.poll(() => requestCount).toBeGreaterThan(initialCount)`;
   - API error test: trailing `waitForTimeout(1000)` removed; the test
     waits for the first mocked `/api/v1/` response and asserts the
     dashboard heading is still visible;
   - three navigation tests: retry loops with a 2000 ms sleep become a
     single `page.goto('/dashboard')` (the config sets the navigation
     timeout; the webServer is ready before tests start);
   - logout test: `waitForTimeout(1000)` and the always-true OR check
     become `expect(logoutItem).toBeHidden()` (no logout route mock
     redirects in this test).
   Test: `npx playwright test e2e/dashboard.spec.ts --project=chromium`.
3. Remaining Playwright spec files with sleeps.
