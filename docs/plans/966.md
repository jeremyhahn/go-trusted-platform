# Plan: #966 test standard (no test sleeps)

## Objective

No test at any tier sleeps: every sleep becomes a bounded polling helper
or an assertion on what the page renders. The Go tiers have no
`time.Sleep` left on main; the remaining sleeps are Playwright
`waitForTimeout` calls in web/e2e.

## Slices (in order)

1. e2esmall: the small web/e2e specs.
2. e2edash: the dashboard specs.
3. e2edev: the devices specs.
4. iam roles/groups: web/e2e/iam.spec.ts, the roles and create/view
   groups tests.
5. iam groups/permissions (this branch): web/e2e/iam.spec.ts, the
   remove-member Groups test and the Permissions test (ten waits).
   Waits for navigation become `waitForURL` on the group detail route;
   the wait after Escape becomes `expect(menu).toBeHidden()`; the retry
   loop retries at once; a wait in front of an `isVisible` check becomes
   `locator.waitFor({ state: 'visible' })` with the same timeout.
   Tests: the existing Groups and Permissions specs, run on chromium.
6. iam apps/policies: web/e2e/iam.spec.ts, the policies and apps tests.
7. to 9. the remaining web/e2e specs.

## Out of scope

- Application code under web/src.
- New shared helpers at file top (the iam slices edit separate hunks of
  one file and must merge without conflict).
