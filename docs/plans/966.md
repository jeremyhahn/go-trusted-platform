# Plan: #966 — no test sleeps

## Objective

The issue's test standard says no test at any tier sleeps: every sleep becomes
a bounded wait on what the page renders or the mocks record. This row branch
carries the Playwright sleep slices of the web e2e suite.

## Slices

1. Sleep slice 1 (earlier lane): first group of Playwright specs.
2. Sleep slice 2 (earlier lane): second group of Playwright specs.
3. Sleep slice 3 (this lane): `web/e2e/devices.spec.ts`, seven sleeps.
   - Row menu "View Details": the 500 ms dropdown sleep goes; the menu item is
     asserted visible with `expect(...).toBeVisible()`.
   - Both 1000 ms navigation sleeps become `page.waitForURL(/\/devices\/1/)`.
   - Fetch-devices error: the 2000 ms sleep becomes `toBeVisible()` on the
     first error or empty-state indicator.
   - Profile view, profile edit and vTPM view: each 500 ms sleep becomes
     `expect.poll` on "navigated to the target path or menu closed".
   - Tests: the edited specs themselves; acceptance is
     `grep -c waitForTimeout web/e2e/devices.spec.ts` = 0 and the spec file
     green on chromium.

## Out of scope

- Application code under `web/src`.
- Sleeps in Go tests and other tiers (other slices of the row).
- Any change to what the tests assert beyond replacing the waits.
