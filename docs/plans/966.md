# Plan: #966 no sleeps at any test tier

## Objective

No test at any tier sleeps: every fixed wait becomes a bounded polling
helper or a wait on an observable event. The Go tiers carry no
`time.Sleep` on main (the bare `<-time.After` waits run inside synctest
bubbles); what remains is `waitForTimeout` in the Playwright specs under
web/e2e.

## Slices

1. Small specs (this slice): the six sleeps in four specs.
   - ca.spec.ts: `expect.poll` on the mock's recorded certificates.
   - tenant-isolation.spec.ts: `expect.poll` on the recorded Bearer header.
   - api-routes-regression.spec.ts: `waitForLoadState('networkidle')`.
   - auth.spec.ts: `toBeFocused()` for the focus check; `waitForResponse`
     on the mocked registration begin route for the two failure tests.
   Tests: the specs themselves, run on chromium.
2. Sleep slice 2: the next group of specs with `waitForTimeout`.
3. Sleep slice 3: the remaining specs, then a check that web/e2e carries
   no `waitForTimeout`.

## Out of scope

- Application code under web/src.
- Go test tiers (already sleep-free on main).
- The one-hour pipeline budget and other #966 standards not about sleeps.
