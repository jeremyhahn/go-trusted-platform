# #1817: unit tests for the CA certificate components

UI epic #1665 support. Web only; no Go change.

## Objective

Every export of `web/src/components/features/ca/` has a unit test next to it,
including edge, error and invalid inputs.

## Slices (one commit each)

1. `cert-chain.test.tsx`: empty chain, root-to-leaf order, connectors,
   current marker (match and no match), expiring soon, expired, revoked.
2. `cert-detail.test.tsx`, `csr-viewer.test.tsx`: fields, handlers and their
   absence, Revoke hidden for revoked or expired, extensions with critical
   marker; CSR metadata variants, clipboard copy and reset, clipboard refusal,
   empty CSR.
3. `cert-table.test.tsx`: empty, loading, columns, expiry colours, row actions
   by status and handler, separators, subject search, paging.
4. `issue-cert-form.test.tsx`: defaults, required subject, submitted values,
   options, validity bounds, cleared validity, async submit, loading state.

Radix dropdown and select popups are replaced by inline mocks in the tests,
as `device-table.test.tsx` does; the components' own handlers are exercised.

## Out of scope

- Changes to the components (no test exposed a bug).
- The pre-existing gate failures on main (unbuilt `trusted-platform-sdk`
  package; lint errors elsewhere).
