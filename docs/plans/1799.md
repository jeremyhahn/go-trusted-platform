# #1799: sdk/javascript client module unit tests

Objective: unit tests for every export of `sdk/javascript/src/client/`
`config.ts`, `factory.ts`, `interceptors.ts` and `wails-client.ts`, with
edge, error and invalid inputs. Part of UI epic #1665.

## Slices (one commit each)

1. `config.test.ts`: default constants, `getDefaultBaseUrl` env precedence
   (Vite, NEXT_PUBLIC_API_URL, API_URL, `/api`), `getDefaultFetch` binding
   and the no-fetch error, `resolveConfig` merging, `validateConfig` errors.
2. `factory.test.ts`: `isWailsRuntime`, `isDesktop`, `getClient` choosing
   the Wails or HTTP client.
3. `interceptors.test.ts`: `InterceptorManager` add/remove/run, and each
   `create*Interceptor` factory.
4. `wails-client.test.ts`: `WailsPlatformClient` against stubbed bindings,
   including missing bindings and binding errors.

A bug a test exposes gets a separate `fix(sdk)` commit after the test.

## Out of scope

No change to the modules except such a fix; no Go change; no other client
files.
