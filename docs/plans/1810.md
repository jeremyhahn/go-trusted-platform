# Plan: #1810 web platform component unit tests

## Objective

Unit tests (vitest + Testing Library, jsdom) for the seven modules in
`web/src/components/features/platform/` that have none, covering every export
with normal, edge, error and invalid inputs.

## Slices (one commit each)

1. `config-section.test.tsx`: title/description/children, form data
   conversion (checkbox, numbers, strings, empty form), pending state, success
   toast, error toast for Error and non-Error rejections, empty/blank fields
   kept as strings.
2. `health-status.test.tsx`: every status value and an unknown status.
3. `log-entry.test.tsx`: each log level, expand/collapse of details,
   entries without details.
4. `log-viewer.test.tsx`: empty list, list rendering, filters and controls.
5. `resource-usage.test.tsx`: CPU/memory/disk values, 0 and 100 percent
   bounds, out-of-range values.
6. `service-health-card.test.tsx`: each health state, optional fields absent.
7. `service-unavailable-state.test.tsx`: default and custom props, retry.

A test that exposes a real bug is followed by a separate `fix(web)` commit.

## Out of scope

Changes to the components beyond a fix a test exposes; e2e (Playwright)
tests; Go code.
