# #1976: unix sockets in tests stay under the 108-byte sun_path limit

## Objective

Main is red: tests bind unix sockets under t.TempDir(), and the runner's
long TMPDIR plus a long test name exceeds sun_path. The CI TMPDIR override
(#1978) does not take effect, so the fix is in the tests: each affected
package gets a `shortSocketDir(t)` helper (a copy of
pkg/cli/commands/sdn/shortsock_test.go) and builds socket paths under it.

## Slices

1. Helpers in pkg/cli/commands/barrier, pkg/api/daemon, pkg/sdn/ovs and
   pkg/sdn/gateway/process; the CI-named failures switched to them:
   barrier run_wired_test.go, daemon cluster_grpc_backend_test.go, every
   ovs `tmpDir`/socket site, process unreachable.sock and the RuntimeDir
   repair test. The CI failures (TMPDIR=/home/runner/_work/_temp) pass.
2. (remainder) The brief's acceptance uses a 61-byte TMPDIR, harsher than
   CI. Under it these still fail and need the same switch:
   - pkg/sdn/ovs appctl_test.go (runDir/dir := t.TempDir()): TestAppCtl*,
     TestDumpDatapathFlowsFilter, TestDumpConntrackZones, TestCoverageShow,
     TestPMDStatsKernelDatapathError, TestDatapathStats.
   - pkg/api/daemon: attestation_verdict_stream_test.go (d.sock),
     TestSDKQUIC_BMCMethods* and the other t.TempDir() platformd.sock
     sites (embedded_*, initonly, mcp_tenant, serving_certificate,
     gateway_backends, fail_closed, transport_construction, and the
     `dir := t.TempDir()` parity helpers).

## Out of scope

- Other packages that pass today; .github/workflows/ci.yml (#1978);
  the FIPS short-key panic (#1979).
