# Plan: #1845 unit tests for the networking dashboard pages, part 2

Part of UI epic #1665. PR #1866, branch `row/1845-web-networking-pages-tests-2`.

## Objective

Vitest unit tests for the networking dashboard pages under
`web/src/app/(dashboard)/networking/`, with no page code changes.

## Slices (in order)

1. SDN ports page (`ports/page.test.tsx`): lists the selected bridge's ports,
   adds and deletes ports, error and refusal states.
2. SDN page (`sdn/page.test.tsx`): lists bridges, topology and flow rules;
   creates bridges.
3. PXE page (`pxe/page.test.tsx`): lists devices and status, shows the
   reporting gateways, registers devices.
4. VLANs page (`vlans/page.test.tsx`): lists, creates and deletes VLANs;
   guards the default VLAN and bad VLAN IDs.
5. Zones page (`zones/page.test.tsx`): lists zones, creates zones with
   defaults and with every policy field.
6. Merge main and confirm the gates: `make web-deps`, `npm run test:unit`,
   `npm run typecheck` in `web/`.

## Out of scope

- Page code changes and fixes for defects the tests find (reported instead).
- Web lint (ungated, #419) and end-to-end/browser tests.
- Networking pages covered by part 1 (e.g. VPN).
