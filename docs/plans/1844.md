# #1844: unit tests for the networking dashboard pages (part 1)

UI epic #1665 support. Web only; no Go change.

## Objective

A vitest + @testing-library test file beside each of these modules, covering
every export with edge, error and invalid inputs, network calls mocked
(following `web/src/app/(dashboard)/networking/vpn/page.test.tsx`):

1. `networking/dns/[zone]/page.tsx`: `generateStaticParams` returns the
   placeholder; `Page` renders the mocked client component.
2. `networking/dns/page.tsx`: zone list load, empty state, error state.
3. `networking/flows/page.tsx`: flow list load, empty and error states.
4. `networking/gateway/page.tsx`: gateway data load, empty and error states.
5. `networking/ipam/page.tsx`: pools/allocations load, empty and error states.
6. `networking/overlays/page.tsx`: overlay list load, empty and error states.

## Slices

One commit per test file, in the order above. A real bug a test exposes is
fixed in a separate `fix(web)` commit after its test commit.

## Out of scope

- The client components of thin route wrappers (tested separately).
- Web lint (ungated, #419).
- The other networking pages (later parts of #1844).
