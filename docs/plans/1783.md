# Plan: #1783 JS SDK Overlay service unit tests

## Objective
Unit tests for every public method of `sdk/javascript/src/services/overlay-service.ts`
with a mocked transport (UI epic #1665).

## Slices
1. Skeleton `src/services/overlay-service.test.ts`: one `describe`, an `it.todo` per method.
2. Fill the tests: for each of getStatus, listVTEPs, getVTEP, createVNI, listVNIs,
   deleteVNI, listTunnels, getTunnelStats, listRemoteMACs, forgetMAC assert the
   transport method, path, query and body, plus one error case per method.
3. A real bug a test exposes gets a separate `fix(sdk)` commit after the test commit.

## Out of scope
- Any Go change; other SDK services; changes to `overlay-service.ts` beyond a real bug.
