# Plan: #334 cluster row (serve wires the daemon's cluster servicer)

## Objective

Every cluster transport (gRPC and Unix ClusterService, REST /api/v1/cluster/*,
QUIC, MCP) answers "cluster service not configured" because nothing in
production calls `Daemon.SetClusterService`. The embedded go-quicbaas SDK
already runs the Raft cluster in-process (`EmbeddedServer.Start`, cluster mode
when the quicbaas config `IsClustered()`). The platform reads that cluster
through the embedded service facade `quicbaasservice.QuicBaaS`
(`ClusterStatus`, `GetLeader`), never through `quicbaassdk.Client.Cluster()`
and never through the build-tagged pkg/cluster coordinator chain.

## Slices

1. #2140 (this slice): serve sets the cluster servicer.
   - `appbackends.ClusterSurface` (ClusterStatus + GetLeader) and
     `NewClusterBackend` / `PlatformClusterBackend` implementing
     `daemon.ClusterServicer`: Status, Nodes, IsLeader, NodeID read the
     embedded service; Bootstrap reports already/not initialized; Join and
     Leave answer Unavailable.
   - `SDKBackendSources.Cluster`, set by `PlatformClusterBackend(a)` in serve
     and in `WireEmbeddedHost`; `WireSDKBackends` calls `SetClusterService`.
   - Tests: `TestClusterBackend_*`, `TestPlatformClusterBackend_NoEmbeddedService`,
     `TestWireSDKBackends_SetsTheClusterServicer`,
     `TestWireSDKBackends_NoClusterLeavesItUnset`,
     `TestPlatformSDKBackendSources_WithoutStorage` (Cluster nil).
2. Runtime membership: Join through the leader's AddNode, Leave through
   RemoveNode; enable those controls on gRPC/REST/UI.
3. Runtime Bootstrap of a node that started standalone (needs a go-quicbaas
   call this SDK version does not have).
4. UI cluster page (#2087) over the now-live transports.

## Out of scope

- The SDK `Client.Cluster()` request-type defect over the embedded transport
  (upstream go-quicbaas).
- Removing or rebuilding the build-tagged ClusterService / pkg/cluster
  coordinator chain.
- Any .proto, generated file or pkg/api/grpc change.
