# Plan #1775: JS SDK Platform service unit tests

Objective: unit tests for every public method of
`sdk/javascript/src/services/platform-service.ts` with a mocked transport
(UI epic #1665 support).

## Slices

1. Skeleton `sdk/javascript/src/services/platform-service.test.ts`: one
   `describe`, an `it.todo` per public method.
2. Fill the tests: for getVersion, getSystemInfo, getTPMInfo, getHealth,
   getConfig, reloadConfig and getMetrics assert the HTTP method, path,
   query and body sent to the transport, and one error case per method
   (a transport rejection propagates).

## Out of scope

- Any change to `platform-service.ts` unless a test exposes a real bug
  (then a separate `fix(sdk)` commit).
- Go code, other SDK services, pre-existing tsc errors.
