# Plan: #1720, BMC users and web certificate pages (slice 3 of epic #1665)

## Objective

Every BMC operation with a REST route is reachable from the web UI and
exercised by a Playwright e2e test with mocked API responses.

Operations: ListUsers, CreateUser, DeleteUser, SetUserPassword,
SetUserPrivilege (`/bmc/{profileID}/users...`) and ReplaceWebCertificate
(`PUT /bmc/{profileID}/cert`).

## Slices, in order

1. `web/e2e/bmc-users.spec.ts`: one `test.describe`, a `test.fixme` per
   operation (the test commit, ruling 286).
2. JS SDK: `sdk/javascript/src/services/bmc-service.ts` in the shape of
   `dns-service.ts`, exported from the services index, with vitest cases
   for each method (path, verb, body).
3. Web: a BMC hook in `web/src/hooks/`, the page
   `web/src/app/(dashboard)/devices/bmc/[profileID]/users/page.tsx`
   (users table, create/password/privilege dialogs, delete and certificate
   replacement behind a confirm dialog) and a nav entry beside the sibling
   device pages.
4. Fill the spec: each fixme becomes a test that mocks the route and
   checks the request the page sends.

## Out of scope

- EnrollBMC and RestoreFactoryCert (no REST route yet).
- Any Go change.
