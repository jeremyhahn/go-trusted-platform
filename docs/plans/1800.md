# Plan #1800: unit tests for the SDK transport layer

## Objective
Give `sdk/javascript/src/transport/transport.ts` a unit test. The module
exports only types: the `Transport` interface and the `TransportKind` union.

## Slices
1. `sdk/javascript/src/transport/transport.test.ts`:
   - type-level: the five verbs of `Transport`, their parameter and
     return types, that `ApiClient` satisfies it structurally, and that
     incomplete objects and wrong argument types are refused
     (`@ts-expect-error`, checked by `tsc --noEmit`);
   - run time: an in-memory transport covering every verb, every
     `RequestBody` shape, an unsuccessful response, and a rejected promise;
   - `TransportKind`: exactly the four kinds, refusal of unknown, wrongly
     cased or empty kinds, and an exhaustive switch.

## Out of scope
- Changes to `transport.ts` or `ApiClient`.
- The tsc errors that already exist in the quicbaas and attestation service
  tests on main.
