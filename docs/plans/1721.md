# Plan: #1721 container detail, exec, metrics and attestation pages

Slice 8 of the UI epic #1665.

## Objective

Every container operation of the compute API is reachable from the web UI
and exercised by a Playwright e2e test with mocked API responses:

- GetContainer (`GET /containers/{id}`)
- ExecContainer (`POST /containers/{id}/exec`)
- AttestContainer (`POST /containers/{id}/attest`)
- GetContainerMetrics (`GET /containers/{id}/metrics`)
- VerifyVMAttestation (`POST /vms/{id}/attest/verify`, VM detail page)

## Slices, in order

1. `web/e2e/compute-containers.spec.ts`: one `test.describe`, a `test.fixme`
   per operation (the test commit, ruling 286).
2. JS SDK: the missing methods in
   `sdk/javascript/src/services/compute-service.ts` with vitest cases.
3. Web: a hook in `web/src/hooks/` for the container operations, the page
   `web/src/app/(dashboard)/compute/containers/[id]/page.tsx` (exec and
   attest behind a confirm dialog), a link from the containers list, and a
   verify action on the VM detail page.
4. Fill the spec: every operation above has a test, mocked through
   `web/e2e/fixtures/api-mock.ts`.

## Out of scope

- Any Go change, go-xkms or go-quicbaas API.
- Container create, start, stop and delete (already on the list page).
