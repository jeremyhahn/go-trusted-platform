# Plan #1732: UI attestation collect, manifest verify and delete (epic #1665, slice 1)

## Objective
Every attestation REST operation without a UI today is reachable from a
dashboard page and covered by a Playwright e2e test with mocked API responses:
VerifyManifest, DeleteManifest, CollectHostAttestation, CollectVMAttestation,
CollectContainerAttestation.

## Slices (in order)
1. `test(web)`: `web/e2e/attestation-collect.spec.ts`, one `test.fixme` per operation.
2. `feat(sdk)`: missing methods on the JS SDK attestation service, with vitest cases.
3. `feat(web)`: `attestation/collect` page (host, VM, container collect),
   manifest verify and delete (delete behind a confirm dialog), a hook in
   `web/src/hooks/`, a nav entry; the e2e spec filled in.

## Out of scope
GetAttestationQuote, VerifyAttestationQuote, DescribeCallerPolicy and
PollDeviceVerdicts (no REST route yet). No Go change.
