# Plan #1732: UI attestation collect, manifest verify and delete (epic #1665, slice 1)

## Objective
Every attestation REST operation without a UI today is reachable from a
dashboard page and covered by a Playwright e2e test with mocked API responses:
VerifyManifest, DeleteManifest, CollectHostAttestation, CollectVMAttestation,
CollectContainerAttestation.

## Slices (in order)
1. `test(web)`: `web/e2e/attestation-collect.spec.ts`, one `test.fixme` per operation.
2. `feat(sdk)`: missing methods on the JS SDK attestation service, with vitest cases.
3. `feat(web)`: `attestation/collect` page (host, VM, container collect),
   manifest verify and delete (delete behind a confirm dialog), a hook in
   `web/src/hooks/`, a nav entry; the e2e spec filled in.

## Departures (#1747 review)
- VerifyManifest is not offered: the verifier does not fail closed yet, and
  making it fail closed is a Go change outside this slice. Deferred until that
  prerequisite lands or the scope is revised (Codex round 2, P1).
- CollectVMAttestation and CollectContainerAttestation always answer
  ErrTPMSessionNotConfigured on the service, so the page shows them gated as
  unavailable; vitest and e2e cover the gate and the real failure response.

## Scope revision (#1747)
#1747 delivers DeleteManifest (behind a confirm dialog) and
CollectHostAttestation, and shows VM and container collection gated as
unavailable. It does not complete #1732: its PR body and commits say
Refs #1732, not a closing keyword, so #1732 stays open for the operations
below. This revision needs the owner's agreement (Codex round 3, P1).

## Remaining in #1732 (issue stays open)
- VerifyManifest: prerequisite is a fail-closed manifest verifier (Go change in the attestation service); then add the verify control and its e2e case.
- CollectVMAttestation: prerequisite is a TPM session configured on the service, so it stops answering ErrTPMSessionNotConfigured; then lift the gate.
- CollectContainerAttestation: same prerequisite as CollectVMAttestation (TPM session configured); then lift the gate.

## Out of scope
GetAttestationQuote, VerifyAttestationQuote, DescribeCallerPolicy and
PollDeviceVerdicts (no REST route yet). No Go change.
