# Plan #1727: UI VM operations (slice 7 of #1665)

## Objective
Every VM operation of the compute API is reachable from the VM detail page
and exercised by a Playwright test with mocked API responses.

Operations: SuspendVM, ResumeVM, GetVM, AttestVM, GetVMMetrics, AttachDisk,
DetachDisk, ResizeDisk, CreateSnapshot, GetSnapshot, MigrateVM,
PrepareMigration, FinalizeMigration.

## Slices
1. `web/e2e/compute-vms.spec.ts`: one `test.fixme` per operation.
2. SDK: missing methods on `ComputeService` with vitest cases.
3. Web: `useVMOperations` in `web/src/hooks/`, a `VMOperations` panel on
   the VM detail page (suspend and resume, attest, metrics, disks,
   snapshots, migrate) and a `/compute/migrations` page (prepare and
   finalize, run on the destination host) with a sidebar entry; detach,
   migrate and finalize sit behind a confirm dialog.
4. Fill the spec: every operation has a test, with the compute routes
   mocked by `mockVMOperationsApi` in `web/e2e/fixtures/api-mock.ts`.

## Out of scope
- Container operations (slice 8, `compute/containers`).
- Go changes; backend behaviour.
