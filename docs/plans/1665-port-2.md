# Epic #1665, #2036 part 2: port the mocked specs to the real-server harness

## Objective
Port this part's mocked Playwright specs to `web/e2e/real-server/`, seeded
through the SDK (`sdk`, `tenant`, `adminPage` from `./fixtures`) and asserting
on server answers. Each mocked original is deleted in the commit that adds
its port. Parts 1 (#2035) and 3 (#2037) keep their own plan files.

## Slices (in order)
1. Done: kms, networking, ntp, overlay, platform, provisioning, registry,
   storage. kms, ntp, overlay and registry are named `<name>-port.spec.ts`
   because other UI rows add specs of the same name.
2. New: iam-groups-tenants, iam-policies, iam, idevid (`idevid-port`),
   invitation-accept-flow, invitation-accept, invitations, kms-ops.

## Gaps for the route audit (part 2)
Mocked cases with no server behaviour behind them, dropped from the ports:
- kms: artificial list latency (loading spinner); injected 500 on list,
  detail, rotate and delete; injected 400 on delete; tenant-member session
  (harness seeds only the admin); the skipped encryption-operations block.
- networking: loading latency; injected 500s on VLAN, gateway, DNS, overlay
  and PXE reads; a 409 from a create-VLAN dialog that does not exist;
  hand-set port and flow counters and UP/DOWN ports; synthetic 503 role
  variants (only the harness node's real role is testable); member session;
  reported-gateway fleet telemetry.
- ntp: a status read held open; a refresh failing on cue (stale mark); a 409
  from Step; a confirmed Step (it would step the runner's clock).
- overlay: 403 denials on delete, forget MAC and the VTEP, tunnel and MAC
  lists; learned remote MACs; tunnel counters and a second node's VTEP.
- platform: unhealthy services on cue; 503 on health, metrics and events;
  latency; member session; the skipped logs and configuration placeholders.
- provisioning: pending and expired sessions; the SDK and API have no call
  that opens a session without a device enrolling, so the list is held to
  whatever the server holds and skips when empty.
- registry: tag list, delete-after-confirm and cancel; the SDK cannot push an
  image and the harness seeds none; the injected 500 status error.
- storage: key-value, vector, time-series and backup CRUD flows (page load
  only); injected 500 on list buckets; member session.

## Out of scope
- Writing the harness or the capability gate.
- Removing `web/e2e/fixtures/*mock*.ts` (other parts still import them).
- Running Playwright in a lane (CI runs the specs).
