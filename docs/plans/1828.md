# Plan: unit tests for the CA dashboard pages (#1828)

Objective: every export of the five CA dashboard page modules has a unit
test, covering the loaded, empty, loading, error and invalid-input paths.

## Slices (one commit each)

1. `ca/bundle/page.test.tsx`: fetch through `ca.getBundle`, loading,
   error, empty, every bundle envelope shape (flat PEM, `payload.bundle.pem`
   base64, `pemData`, string `bundle`, undecodable string), certificate
   count, Refresh, Copy (success and refused clipboard), Download.
2. `ca/certificates/page.test.tsx`: the certificate list page.
3. `ca/certificates/[id]/page.test.tsx`: `generateStaticParams` and the
   default `Page` wrapper.
4. `ca/crl/page.test.tsx`: the CRL page.
5. `ca/requests/page.test.tsx`: the certificate requests page.

Tests stub `@/hooks` with `vi.mock` so each case sets the `useApi` state.

## Out of scope

- Changes to the page modules, unless a test exposes a real bug (then a
  separate `fix(web)` commit after the test commit).
- `cert-detail-client.tsx` beyond what `Page` renders.
- Any Go change.
