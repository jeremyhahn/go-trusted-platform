# Plan: JS SDK IDevID service unit tests (#1785)

Objective: unit-test every public method of
`sdk/javascript/src/services/idevid-service.ts` with a mocked transport
(UI epic #1665 support).

## Slices

1. `test(sdk)`: `sdk/javascript/src/services/idevid-service.test.ts`.
   For each of the 19 public methods (IDevID: generate, info, exists,
   delete, CSR, install/get/delete certificate; IAK: the same eight;
   device attributes, flush, activate credential) one test asserting the
   HTTP method, path, query and body sent to the transport, and one error
   case (a transport rejection or error response propagates).
2. `fix(sdk)` only if a test exposes a real bug in the service.

## Gates

`npx vitest run` and `npx tsc --noEmit` in `sdk/javascript`
(pre-existing tsc errors on main excepted).

## Out of scope

- Any Go change; the other untested JS SDK services; UI changes.
