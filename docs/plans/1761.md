# Plan: web lint clean on main (#1761, UI epic #1665)

## Objective
`npm run lint` in `web/` reports 25 errors on main 641fd51b2. Fix every one at
its line without rule-disable comments and without changing the eslint
config, so a UI slice's lint result means something.

## Error classes and the fix for each
- `react-hooks/set-state-in-effect` on a fetch-on-mount loader: the loader
  returns data and sets no state; the effect starts it and settles the
  result into state from the promise callbacks (the React docs pattern).
  Refresh handlers set the loading flag and await the same settle path.
- `set-state-in-effect` on a "mounted" flag: `useHydrated` from `@/hooks`.
- `set-state-in-effect` on state derived from a prop (form reset on open,
  first bucket, seal dialog from the query): adjust state during render
  against the previous value, or derive it, as the React docs advise.
- `react-hooks/immutability` (function used before its declaration):
  declare the function before the effect that calls it.
