# Plan: #1734 UI KMS crypto operations (slice 20 of epic #1665)

## Objective
Make every KMS REST operation of the slice reachable from the web UI and
exercised by Playwright: ImportKey, UpdateKeyStatus, GetKeyVersions,
BatchEncrypt, BatchDecrypt, Hash, HMAC, VerifyHMAC, GenerateRandom,
GenerateDataKey, GenerateWrappedDataKey, BackendStatus.

## Slices, in order
1. `web/e2e/kms-ops.spec.ts`: one `test.describe`, a `test.fixme` per
   operation (test commit).
2. JS SDK: add the missing methods to `KMSService`
   (`sdk/javascript/src/services/kms-service.ts`) with vitest cases, one
   per method, asserting method, path and body.
3. Web: a hook in `web/src/hooks/` wrapping the operations, the page
   `web/src/app/(dashboard)/kms/operations/page.tsx` (status change behind a
   confirm dialog) and a nav entry next to the KMS pages.
4. Fill the spec: each operation driven from the page against mocked
   API routes (`page.route`), asserting the request and the rendered result.

## Out of scope
- Rewrap and the operations of the slice without a REST route.
- Any Go change; go-xkms and go-quicbaas APIs.
