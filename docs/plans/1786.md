# Plan: JS SDK vTPM service unit tests (#1786)

## Objective

Unit-test every public method of `sdk/javascript/src/services/vtpm-service.ts`
(`VTPMService`) against a mocked transport, asserting the HTTP method, path,
query and body of each call, plus one error case per method.

## Slices

1. `test(sdk)`: `sdk/javascript/src/services/__tests__/vtpm-service.test.ts`
   (the directory every other service test lives in), one `describe` with:
   - bundles: `createBundle`, `getBundle`, `deleteBundle`, `listBundles`
     (no options; mode, labels, deviceProfileId filters; limit/offset to
     page), `validateBundle`, `getBundlePath`, `getTPMSocketPath`,
     `getNVRAMPath`;
   - templates: `createTemplate`, `getTemplate`, `deleteTemplate`,
     `listTemplates`, `cloneTemplate`;
   - path segments are encoded; each method surfaces a transport error.
2. `fix(sdk)` only if a test exposes a real bug in `vtpm-service.ts`.

## Out of scope

- Any change to `vtpm-service.ts` not forced by a failing test.
- Tests of the other SDK services; Go code; the web UI.
