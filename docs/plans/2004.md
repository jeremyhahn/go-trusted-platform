# Plan: #2004 — MCP refuses tokens with no tenant (SPEC row 123)

## Objective

`QuicBaaSAuthAdapter.CheckPermission` (pkg/api/mcp/dragondb_auth.go) mapped a
token with an empty tenant claim to a configured `defaultTenantID` and sent
the PEP a check for that tenant. A token without a tenant must be refused
before any policy check, so no request is evaluated against a tenant the
token never named.

## Slices

1. Test: `TestQuicBaaSAuthAdapter_CheckPermission` case "refuses a token with
   no tenant without calling the PEP": the error is a `QuicBaaSAuthError`
   with `QuicBaaSAuthErrorClaimsExtraction`, allowed is false and the mock
   PEP records zero `Check` calls. Replaces the "uses default tenant" case.
2. Fix: `CheckPermission` returns that error on an empty tenant; remove the
   `defaultTenantID` field, `QuicBaaSAuthConfig.DefaultTenantID` and
   `SetDefaultTenantID`, and their tests. The daemon wiring
   (`createMCPAuthAdapter` in pkg/api/daemon/daemon.go) never set the field,
   so it needs no change.

## Out of scope

- The IAM web middleware `DefaultTenantID` (pkg/webservice/v1/middleware/iam).
- go.mod, go.sum, workflows; any other row.
