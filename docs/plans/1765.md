# Plan: #1765 JS SDK DNS service unit tests

Objective: every public method of `sdk/javascript/src/services/dns-service.ts`
has a unit test over a mocked transport that asserts the verb, path, query and
body, plus an error case per method. Supports UI epic #1665.

## Slices

1. Test skeleton: `src/services/dns-service.test.ts` with one `it.todo` per
   public method.
2. Filled tests (mocked `ApiClient`, as in `compute-service-wire.test.ts`):
   - zones: createZone, getZone (encoded name), listZones (no query; page,
     pageSize to limit, internalOnly/publicOnly as strings), updateZone (only
     ttl and description in the body), deleteZone;
   - records: addRecord (record wrapped), listRecords (type filter and none),
     updateRecord (old and new record), deleteRecord (zone, type, name);
   - DNSSEC: signZone (empty body), getDNSSECStatus;
   - resolution: resolve, register;
   - errors, per method: an error response is returned unchanged, and a
     transport rejection propagates.

## Out of scope

- Changes to `dns-service.ts` (none exposed by the tests).
- The pre-existing tsc errors in `src/services/quicbaas/__tests__` and
  `src/services/__tests__/attestation-service.test.ts`, also on main.
- The other JS SDK services without tests.
