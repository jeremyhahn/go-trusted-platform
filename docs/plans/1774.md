# Plan: JS SDK Gateway service unit tests (#1774, UI epic #1665)

## Objective

Every public method of `sdk/javascript/src/services/gateway-service.ts` has a
unit test on a mocked transport that asserts the HTTP verb, the exact path
(no query string: no Gateway method takes list options), the body, and one
error case (a transport rejection reaches the caller).

## Slices

1. `test(sdk)`: `sdk/javascript/src/services/__tests__/gateway-service.test.ts`
   (next to the other service tests, the vitest convention of this SDK).
   - status: `getStatus`, `setMode`
   - telemetry state: `listState`, `getState`, `deleteState` (id encoded)
   - NAT64: `getNAT64Status` (absolute daemon path, not basePath)
   - BGP: `getBGPStatus`, `listBGPPeers`, `announcePrefix`, `withdrawPrefix`
     (DELETE `/bgp/prefixes?prefix=<CIDR>`, encoded, no body),
     `listAnnouncedPrefixes`
   - IPAM: `listIPAMPools`, `allocateIP` (POST `/ipam/allocations`, poolId,
     deviceId and hostname in the body), `releaseIP` (DELETE
     `/ipam/allocations?ip=<addr>`, IPv6 encoded), `listAllocations` (all,
     one pool as `?poolId=`, and an empty pool id)
   - one rejection case per method (table-driven).
   - Expected requests are derived from the routes and handlers registered in
     `pkg/webservice/v1/rest/gateway/router.go` (Codex P1 on #1781), not from
     the SDK's earlier paths, which that router does not serve.
2. `fix(sdk)`: `listAllocations` treats an empty `poolId` as "all pools",
   as `ListAllocationsRequest` documents, instead of requesting
   `/ipam/pools//allocations`.
3. `fix(sdk)`: `withdrawPrefix`, `allocateIP`, `releaseIP` and the
   pool-filtered `listAllocations` send the method, path and body the Go
   router serves (they requested paths that return 404).
4. `fix(gateway)` (Codex round 2 P1 on #1781): the router's
   `listAllocations` forwards the `poolId` (or `pool_id`) query parameter as
   `ListAllocationsRequest.pool_id`, so the SDK's pool-filtered call lists
   that pool only; route cases in `router_handlers_test.go` cover both names.

## Out of scope

- The other untested SDK services; any other Go or server change.
- Pre-existing tsc errors in `src/services/quicbaas/__tests__` and
  `attestation-service.test.ts`.
