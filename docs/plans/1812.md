# Plan: unit tests for the IAM web components (#1812, UI epic #1665)

## Objective

The six modules in `web/src/components/features/iam` have no unit test.
Add one vitest + Testing Library test file per module, covering every
export, including empty, edge, error and invalid inputs.

## Slices (one commit each)

1. `permission-tree.test.tsx`: empty list message; groups sorted by
   resource, actions sorted; group count; toggling one permission adds or
   removes it; group checkbox selects or clears the group, keeps other ids;
   indeterminate state; disabled; collapse hides the items.
2. `role-picker.test.tsx`: renders roles, selection, change callback,
   empty and disabled states.
3. `token-display.test.tsx`: shows the token, copy to clipboard, the
   one-time warning, close callback.
4. `token-form.test.tsx`: required name, scope selection, submit payload,
   refusal shown, cancel.
5. `user-form.test.tsx`: create and edit modes, validation of required and
   invalid fields, submit payload, refusal shown.
6. `user-table.test.tsx`: `createUserColumns` columns, status badges,
   row actions, empty table.

## Out of scope

- No change to the modules unless a test exposes a real bug (then a
  separate `fix(web)` commit after the test commit).
- No Go change, no other package.
