# Plan: #1695 installer default seal PCRs 7 and 11

## Objective

`docs/SPEC.md` (installer row) says the seal's PCR selection is the board
config's `seal-pcrs`, default 7 and 11. The code defaulted to `{0, 7, 9}` in
several places. Make 7 and 11 the one default, defined once.

## Slice 1 (done)

Tests first:
- `TestDefaultSealPCRs` (`pkg/installer`): the constant, the generator, a
  profile and the loader all give `[7 11]` when TPM sealing is on and no PCRs
  are set; the loaded slice is a copy of the default.
- `TestDefaultConfig_SealPCRs` (`pkg/iso`): `DefaultISOBuildConfig` gives
  `[7 11]`, a fresh slice each call.
- Existing tests that pinned the old default (`config_generator_test`,
  `coverage_boost_test`, `errors_test`, `types_test`) move to 7 and 11.

Change:
- `pkg/installer/types.go`: `DefaultSealPCRs = []uint{7, 11}`.
- Use it (as a copy) in `config_generator.go`, `profiles.go`,
  `config_loader.go`, `pkg/iso/config.go`, `pkg/iso/customize.go`
  (`pkg/iso` already imports `pkg/installer`, no cycle).
- `pkg/iso/types.go` `SetDefaults` string default `"0,7,9"` becomes the same
  selection (a sixth site the issue did not list).
- `pkg/iso/errors.go`: the missing-`seal-pcrs` error text says `[7, 11]`;
  the `installer.go` baked-config hint names it too.

Docs:
- `docs/installer/engineering.md`: state the default.

## Folded item #356: signed ISO kernel and initrd (not started)

State in code: `pkg/iso/customize.go` `signISOBootloader` signs only the
standalone GRUB EFI with the media db key. There is no shim, so once GRUB
runs nothing verifies the kernel or the initrd (its SCOPE comment, #354).

Blocked on a design choice the item's text must make (the lane cannot read
#356 or #354; the row checklist line is truncated):
- (a) Authenticode-sign the kernel with the db key and have GRUB hand it to
  firmware `LoadImage`, so the firmware verifies it. This covers the kernel
  only; the initrd stays unverified.
- (b) GRUB `check_signatures=enforce` with an embedded public key and
  detached signatures over the kernel, the initrd and grub.cfg.
- (c) Boot a signed UKI (kernel, initrd and cmdline in one signed image)
  from the ISO in place of GRUB `linux`/`initrd` (`TestBuildISO_WithPreSignedUKI`
  shows a pre-signed UKI path already exists).
Each choice needs a test in `pkg/iso` that fails while the kernel or initrd
is unsigned.
