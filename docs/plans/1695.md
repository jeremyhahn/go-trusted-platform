# Plan: #1695 installer default seal PCRs 7 and 11

## Objective

`docs/SPEC.md` (installer row) says the seal's PCR selection is the board
config's `seal-pcrs`, default 7 and 11. The code defaults to `{0, 7, 9}` in
several places. Make 7 and 11 the one default, defined once.

## Slice 1 (this lane)

Tests first:
- `TestDefaultSealPCRs` (`pkg/installer`): the constant, the generator, a
  profile and the loader all give `[7 11]` when TPM sealing is on and no PCRs
  are set; the loaded slice is a copy of the default.
- `TestDefaultConfig_SealPCRs` (`pkg/iso`): `DefaultISOBuildConfig` gives
  `[7 11]`, a fresh slice each call.
- Existing tests that pinned the old default (`config_generator_test`,
  `coverage_boost_test`, `errors_test`, `types_test`) move to 7 and 11.

Change:
- `pkg/installer/types.go`: `DefaultSealPCRs = []uint{7, 11}`.
- Use it (as a copy) in `config_generator.go`, `profiles.go`,
  `config_loader.go`, `pkg/iso/config.go`, `pkg/iso/customize.go`
  (`pkg/iso` already imports `pkg/installer`, no cycle).
- `pkg/iso/types.go` `SetDefaults` string default `"0,7,9"` becomes the same
  selection (a sixth site the issue did not list).
- `pkg/iso/errors.go`: the missing-`seal-pcrs` error text says `[7, 11]`.

Docs:
- `docs/installer/engineering.md`: state the default.

## Out of scope

- The `luks-root` named policy (blocked on go-xkms).
- Built-in profile YAMLs that set `seal_pcrs` explicitly, and the
  installer's runtime hint text in `installer.go`.
- No go.mod change.
