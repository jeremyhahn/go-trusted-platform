# Plan: SPEC row `provisioning` — `platformctl pxe` command group (#1694)

## Objective

`docs/provisioning/architecture.md` records that no `platformctl pxe` group
exists, as a gap rather than a decision. The SDK already exposes
`platform.Client.PXE()` (a `platformv1.PXEServiceClient`), so the CLI can
drive the PXE provisioning workflow without any new API in the pinned lower
releases.

## Slices

1. `pkg/cli/commands/pxe/` (this slice)
   - verbs: `list`, `get`, `authorize`, `quarantine`, `retry`, `events`;
   - client from `platform.Client.PXE()` through a replaceable factory;
   - typed errors in `errors.go` (missing device ID, missing reason, an
     unknown `--state`, a failed RPC wrapping its cause);
   - registered in `pkg/cli/commands/root.go`;
   - documented in `docs/provisioning/cli.md` §5.
   - Tests (against a fake `PXEServiceClient`):
     `TestAuthorize_SendsDeviceID`, `TestQuarantine_RequiresReason`,
     `TestList_Table`, plus get/retry/events and the state filter.

2. #374: E2E provisioning Phases 2 and 3 assert on serial-log markers
   (`INTEGRATION_TEST_SERVER_BOOT_MARKER`, `INTEGRATION_TEST_CLIENT_ENROLL_MARKER`,
   required with the ISOs) instead of logging after a budget elapses;
   `docs/provisioning/architecture.md` no longer says the pxe group is missing.
   - Tests: `TestWaitForSerialMarker_*`, `TestProvisioningMarkersFromEnv_RequiresBoth`.
2b. Codex round 1 on #1896, finding 3 (open): `test/integration/pxe` CLI
   leg still asserts the CLI gap (`assertPXECLIGap`, probe runs
   `pxe device list`). Implement CLIAdapter's GetDevice, ListDevices,
   AuthorizeDevice, QuarantineDevice, RetryDevice, GetEvents by shelling
   `platformctl --output json pxe <verb>` and decoding the proto reply
   (as `sdk_adapter.go` deviceResult does); keep ErrCLIPXENotImplemented
   for register/remove/get-by-mac/update-state/set-enrolled/status; the CLI
   leg seeds devices through the gRPC adapter, then drives the six verbs.
3. #240 webhook authentication and HMAC secret.
4. #1379 tp-pxeInstaller certificate authorizes only install completion.
5. #1370 critical installer-marker EKU on PXE install certificates.

## Out of scope

- `register`, `remove`, `update-state`, `set-enrolled`, service
  `status`/`start`/`stop` and the webhook RPC: a later slice of the row.
- Integration targets for the group (REST/MCP transports of the PXE
  service): a later slice.
- Any go.mod change or lower-module bump.
