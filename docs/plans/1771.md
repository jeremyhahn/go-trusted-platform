# Plan: JS SDK IAM service unit tests (#1771)

Part of the UI epic #1665.

## Objective

Every public method of `sdk/javascript/src/services/iam-service.ts` has a
unit test with a mocked transport that asserts the HTTP method, the path,
the query string and the body, plus one error case per method.

## Slices

1. Skeleton: `sdk/javascript/src/services/iam-service.test.ts` with one
   `describe` and an `it.todo` per public method.
2. Fill the tests, grouped by area: users, roles, groups, auth, tenants,
   policies, applications. Each method gets a wire test (method, path,
   query, body) and an error test (the transport's error is returned).
3. If a test exposes a real bug in `iam-service.ts`, a separate
   `fix(sdk)` commit after the test commit.

## Gates

`npx vitest run` and `npx tsc --noEmit` in `sdk/javascript`.

## Out of scope

- Other JS SDK services without tests.
- Any Go change.
