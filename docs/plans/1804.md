# #1804: unit tests for the untested web hooks

## Objective

Five hook modules in `web/src/hooks` have no unit test. Add one vitest file
per module, covering every export with edge, error and invalid inputs.

## Slices (in order, one commit each)

1. `use-device-toggle.test.tsx`: the mutation sends enable/disable to the
   right service call, propagates a rejection, toasts success (both
   re-attestation wordings) and calls onChanged, toasts a refusal as
   destructive without onChanged.
2. `use-toast.test.tsx`: `useToast` toast/dismiss/toasts, default and custom
   duration, no auto-dismiss at duration 0 or below, sharing between hooks,
   unsubscribe on unmount; standalone `toast` and `dismissToast`, unknown id.
3. `use-logout.test.tsx`: every export, success and failure paths.
4. `use-reported-gateways.test.tsx`: every export, empty, error and
   malformed responses.
5. `use-signed-in-identity.test.tsx`: every export, signed-in, signed-out
   and malformed token cases.

A test that exposes a real bug gets a separate `fix(web)` commit after it.

## Out of scope

- Changes to the hook modules other than a bug fix a test exposes.
- Any Go change; other hooks that already have tests.
