# Plan: unit tests for the web layout components (#1819, UI epic #1665)

## Objective

The four layout modules in `web/src/components/layout` have no unit test of
their own. Add one test file per module covering every export, including
edge, empty and invalid inputs.

## Slices (in order)

1. `app-sidebar.test.tsx`: `AppSidebar` brand and navigation groups, active
   link state, the group holding the active child opens, other groups stay
   closed, an unknown or missing path opens none, the footer account (with
   and without tenant, signed out), the account menu entries, log out calls
   the handler, props pass through.
2. `breadcrumbs.test.tsx`: `Breadcrumbs` for the root, nested and unknown
   paths, links on ancestors only.
3. `header.test.tsx`: `Header` renders its controls and the account menu.
4. `page-header.test.tsx`: `PageHeader` title, optional description and
   actions, empty values.

Each slice is its own `test(web): ...` commit. A real bug a test exposes is
fixed in a following `fix(web): ...` commit.

## Out of scope

- Any change to the modules themselves, other than such a fix.
- Go code, end-to-end tests, visual styles.
