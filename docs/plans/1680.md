# Plan: #1680 VPN peers and posture policy Playwright e2e (epic #1665, slice 33)

## Objective
Every VPN operation (EnrolPeer, ListPeers, RevokePeer, GetStatus,
GetPosturePolicy, SetPosturePolicy, DeletePosturePolicy, ListPosturePolicies)
is reachable from `/networking/vpn` and exercised by a Playwright test with
mocked API responses.

## Slices
1. `web/e2e/vpn.spec.ts`: skeleton with one `test.fixme` per operation.
2. Fill each test: mock the VPN API routes, visit the page, drive the
   operation through the UI and assert the request and the rendered result.
3. Only where a test finds a gap (missing button, form or confirm): fix
   `web/src/app/(dashboard)/networking/vpn/page.tsx` in a separate commit.

## Gates
`npm run typecheck`, `npm run lint`, `npm run test:unit` in `web/`;
`npx playwright test e2e/vpn.spec.ts --project=chromium`.

## Out of scope
Go changes, SDK changes, other networking pages.
