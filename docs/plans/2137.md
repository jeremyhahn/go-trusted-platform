# Plan: #2137 CAService InitCA, InstallCACertificates, UninstallCACertificates

## Objective

The daemon's CAGRPCService answers Unimplemented for InitCA,
InstallCACertificates and UninstallCACertificates, and REST has no route for
them. Wire all three to what already exists (Go half of #2135), gated by the
admin scopes already in the gRPC catalog: InitCA `ca:create`, install and
uninstall `trust:write`.
