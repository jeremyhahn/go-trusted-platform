# #669: SPEC row factory-image

Row branch `row/669-factory-image`, one PR. The image itself is on main
(epic #667, PRs #677-#682): `make image-rpi`, `platformctl diskimage`, the
userspace and QEMU virt integration suites, and `docs/factory-image/`.

## Objective

The SPEC row's acceptance (docs/SPEC.md): every image, an upgrade included,
is built and signed centrally and **carries a measurement manifest**: a
signed CoRIM (draft-ietf-rats-corim-11) of the PCR values the image
determines, **registered in the go-quicbaas reference-values store**. That
manifest is the part not built. Today the image has no manifest. The repo has
no CoRIM encoder and no PCR prediction from image artefacts. The pinned
go-quicbaas v0.12.0-alpha has no reference-values verbs.

## Slices, in order

1. **Plan and status** (done): this file. user.md and
   docs/firmware/rpi.md say that the image carries no measurement manifest
   yet, and why.
2. **Manifest design** (done): `docs/factory-image/architecture.md` §8.
   It sets out the following:
   - the PCRs the image determines: 0, 4, 7 and 9, plus 11 and 1/2/5 if
     the replay proves them;
   - that runtime PCRs are never in the manifest;
   - the prediction, the CoRIM/CoMID shape, and the KMS-held signing key;
   - registration and three open questions.
   The design is approved before slice 3 starts.
3. **PCR prediction**: compute the predicted digests per bank from the
   staged UKI, U-Boot and Secure Boot keys. Test: the unit tests fix each
   PCR's value for the `diskimagetest` fixtures.
4. **CoRIM encode and sign**: write `measurements.corim` (COSE_Sign1) next
   to `manifest.json` / `SHA256SUMS` on every image and upgrade build. Tests:
   encode/decode round trip, a signature check, a refusal on a missing
   input.
5. **Event-log reproduction**: `make integration-test-diskimage` checks that
   the manifest's values equal the live TCG event log replay on the QEMU
   virt aarch64 stand-in. The x86 ISO path gets the same check.
6. **Registration**: `platformctl diskimage` registers the manifest through
   `Security().Attestation().PutReferenceValues`. Blocked: that verb ships
   in go-quicbaas v0.14.0-alpha, and only v0.12.0-alpha is pinned and
   fetchable (#720, #906/#937, go-xkms #1443).
7. **Hardware validation** (operator): a Pi 4 with the SLB9670 follows
   user.md's runbook and attests. The operator does this on the device.
8. The row PR marks `factory-image` shipped in docs/SPEC.md.

## Out of scope

Pi OTP signed boot, A/B partitions, OTA (docs/firmware/rpi.md stays
PLANNED), Pi 5 beyond the experimental model entry, firstboot LUKS re-key.
