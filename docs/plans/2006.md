# Plan: #2006 daemon refuses tenant-scoped calls from unbound callers (SPEC row 109)

## Objective

Tenant-scoped IAM and tenant operations in the daemon run only for a caller
bound to a tenant. A caller with no identity is refused; a bound caller
reaches its own tenant and is refused PermissionDenied for any other.

## Slices (PR #2031)

1. Refuse unbound callers in the daemon's tenant authorization
   (iam_tenant_authz.go). Tests: test callers carry the operator identity;
   an unbound caller is refused.
2. REST and gRPC local-JWT callers stay bound to their tenant
   (bindLegacyPrincipal, PrincipalTokenValidator in pkg/api/grpc). Tests:
   REST session and gRPC local JWT reach their own tenant only.
3. Round 2 P1: QUIC local-JWT callers on the legacy (bool-only) validator
   path stay bound. pkg/api/quic gets a separate legacy-principal context key
   and an optional PrincipalTokenValidator; callerTenant reads it. The
   principal is not stored as a platform-token AuthorizedContext, so
   AuthorizeRequest enforces no scp scopes on a scope-free local JWT.
   Tests: principal stored and bound; a validator without TokenPrincipal
   leaves the caller unbound; a TokenPrincipal error is Unauthorized;
   callerTenant allows the own tenant and refuses another.

## Out of scope

- Scope enforcement for local JWTs.
- MCP and platform-token paths (already bound).
