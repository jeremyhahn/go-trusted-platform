# Plan: #2006, deny tenant-scoped IAM/tenant calls from unbound callers (SPEC row 109)

## Objective

The shared IAM and tenant authorizers (`authorizeIAMTenant`,
`authorizeSystemCaller`, `TenantGRPCServer.authorizeTenant` and
`authorizeTenantName` in `pkg/api/daemon`) admit any caller that carries no
tenant-bound identity. A caller with no identity at all (no platform token,
no mTLS identity, no Unix peer credentials) must be refused with
`codes.PermissionDenied`, fail closed.

The local operator stays admitted: a Unix-socket caller carries
kernel-verified SO_PEERCRED credentials (`peercred.UnixCredentials`), and an
in-process embedder carries the process credentials
(`peercred.ContextWithProcessCredentials`). Those are the operator path
`callerTenant` documents, not an anonymous caller.

## Slices

1. `test(daemon)`: in `iam_tenant_authz_test.go`, a context with no identity
   gets PermissionDenied from `authorizeIAMTenant`, `authorizeSystemCaller`,
   `authorizeTenant` and `authorizeTenantName`; a context with Unix peer
   credentials is still admitted by each. (Red until slice 2.)
2. `fix(daemon)`: one helper, `authorizeUnboundCaller`, used by every
   `!bound` branch: Unix peer credentials admit, anything else is
   PermissionDenied. Doc comments updated.

## Departure (open decision)

Slice 2 turns about 85 existing daemon tests red. Most seed or call through a
bare `context.Background()` (tenant_grpc_server_coverage_test.go,
iam_role_ids_test.go, iam_mcp_parity_test.go, mcp_tenant_test.go,
rest_tenant_authz_test.go fixtures) and need `unixOperatorContext()`.
`TestTenantServerAdmitsUnboundCaller` asserts the old design and must be
inverted. The QUIC and MCP SDK tests (tenant_quic_sdk_test.go,
tenant_mcp_sdk_test.go, quic_iam_category_test.go) drive real servers whose
local caller has no identity: QUIC under SkipIAMValidation has no peer
credentials, and MCP has no CallerContext hook (only embedded_host sets
process credentials). Open decision: should those callers be refused (then
the fixtures need platform tokens), or should the MCP stdio / SkipIAMValidation
servers stamp process credentials like embedded_host does?
