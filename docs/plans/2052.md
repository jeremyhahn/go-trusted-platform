# Plan: #2052 GatewayService load balancer, NAT64 and perf in the web UI

Epic #1665 slice 15 (ruling 972). The in-process GatewayService implements
the load-balancer, NAT64 and perf verbs; the webservice, the JS SDK and the
web UI do not reach them yet. Ten operations do not fit one lane, so the row
goes in four slices on branch `row/2052-ui-gateway-vip`.

## Objective

Every GatewayService LB/NAT64/perf operation has a webservice REST route
(Go test), an SDK method (vitest), a web hook (vitest) and, last, a gated
control on the gateway page with a Playwright spec, and the coverage matrix
rows 291-300 read `covered`.

## Slices

1. LB reads (this slice): `GET /api/v1/gateway/lb/vips`,
   `GET /api/v1/gateway/lb/vips/{protocol}/{address}/{port}`,
   `GET /api/v1/gateway/lb/status` on the webservice (admin gate, protojson);
   SDK `listVIPs`, `getVIP`, `getLBStatus` and the VIP types; web hook
   `useGatewayVIPs`. Tests: `router_lb_test.go`
   (`TestGatewayRouter_LBReadsForwardToTheService`, error mapping, bad port
   400, nil server 503, no write routes), `gateway-service-lb.test.ts`,
   `use-gateway-vips.test.tsx`; routes.golden gets three lines.
2. LB writes: `POST /lb/vips` (AddVIP, 201), `DELETE /lb/vips/{p}/{a}/{port}`
   (RemoveVIP), `PUT /lb/vips/{p}/{a}/{port}/backends` (SetVIPBackends, URL
   keys win); SDK `addVIP`, `removeVIP`, `setVIPBackends`; hook mutations;
   remove `TestGatewayRouter_LBHasNoWriteRoutes`.
3. NAT64 and perf reads: serve `/api/v1/sdn/gateway/nat64/status` on the
   webservice in the daemon snake_case shape the SDK already types;
   `GetPerfDatapath` and `GetPerfConntrack` read routes, SDK methods, hook.
   `GetPerfFlows` mutates the OVS bridge (a benchmark under the write lock):
   needs a coordinator ruling before any lane serves it.
4. UI: load-balancer view on the gateway page on `useGatewayVIPs`, every
   control in `<Gated op=...>` once #2159 lands; page vitest;
   `test/integration/web/gateway-lb.spec.ts`; matrix rows 291-300 and the
   summary row updated.

## Out of scope

- The daemon REST (`pkg/api/rest/gateway_lb_handlers.go`), the gateway gRPC
  service and the gatewayd IPC.
- `web/src/hooks/index.ts` and the hooks open train PR #2125 rewrites.
- A `make web-e2e` target.
