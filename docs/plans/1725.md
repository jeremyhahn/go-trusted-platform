# Plan: #1725 UI TPM PCR extend, credential, random and event log e2e

Slice 32 of the UI epic #1665.

## Objective

Every TPM operation below is reachable from a dashboard page and covered by
the Playwright spec `web/e2e/tpm-ops.spec.ts` with mocked API responses:

- GetEventLog (`GET /eventlog`): existing event log page
- ExtendPCR (`POST /pcrs/extend`): PCRs page
- MakeCredential (`POST /make-credential`): new credential page
- ActivateCredential (`POST /activate-credential`): credential page, behind a confirm dialog
- GetRandom (`POST /random`): credential page

## Slices

1. `test(web)`: the spec skeleton, one `test.fixme` per operation.
2. `feat(sdk)`: missing TPM service methods with vitest cases.
3. `feat(web)`: hook in `web/src/hooks/`, the credential page, the nav entry,
   extend PCR on the PCRs page; the spec filled.

## Out of scope

Go changes, backend API changes, other TPM pages.
