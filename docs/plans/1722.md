# Plan: #1722 UI overlay VTEPs, tunnels, VNI delete, MAC forget (slice 22 of #1665)

## Objective
Every overlay REST operation without a UI gets one: ListVTEPs, GetVTEP,
DeleteVNI, ListTunnels, GetTunnelStats, ForgetMAC; each is exercised by
a Playwright test in `web/e2e/overlay.spec.ts` with mocked API responses.

## Slices
1. `web/e2e/overlay.spec.ts`: one `test.describe`, one `test.fixme` per operation.
2. SDK: every method exists; `getTunnelStats` and `forgetMAC` called path
   routes the server lacks, so they move to the server's query routes
   (`/tunnels/stats?remote_vtep=&vni=`, `DELETE /macs?mac=&vni=`), with
   vitest wire cases for all six operations.
3. Web: hook in `web/src/hooks/`, page
   `web/src/app/(dashboard)/networking/overlays/vteps/page.tsx`
   (destructive actions behind a confirm dialog), nav entry.
4. Fill the spec: one test per operation, mocks through `mockOverlayApi` in `web/e2e/fixtures/api-mock.ts`.

## Out of scope
- ListRemoteMACs and GetOverlayStatus (no REST route yet).
- Any Go change.
