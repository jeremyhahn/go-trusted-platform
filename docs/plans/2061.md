# #2061 ProxyService in the UI (epic #1665 slice 24, ruling 972)

## Objective

The web UI covers all 14 ProxyService operations through the JavaScript SDK,
capability-gated, with a REST route on the webservice (`/api/v1/proxy`,
pkg/webservice/v1) for each one, since the web SDK is REST and the
webservice has no proxy route today (only the daemon listener serves
pkg/api/rest/proxy_handlers.go).

## Slices, in order

1. **Reads (this slice).** New pkg/webservice/v1/rest/proxy router with the
   seven reads (`GET /routes`, `/routes/{id}`, `/pools`, `/pools/{id}`,
   `/config`, `/status`, `/zone-matrix`), admin gate plus `proxy:read`;
   daemon accessor `ProxyGRPCServiceServer`, registry and serve.go wiring;
   SDK `ProxyService` (`client.proxy`) read methods.
   Tests: `TestProxyRouterServesEveryReadOperation`,
   `TestProxyRouterMapsServiceRefusals`,
   `TestProxyRouterWithoutAServiceIsUnavailable`,
   `TestProxyRouterRequiresProxyRead`, `TestProxyRouterHasNoWriteRoutes`,
   routes.golden lines, vitest proxy-service.test.ts. Matrix REST column for
   the seven reads (status stays `missing`).
2. **Writes.** `POST /routes`, `PUT /routes/{id}`, `DELETE /routes/{id}`,
   `POST /pools`, `PUT /pools/{id}`, `DELETE /pools/{id}`, `POST /reload`
   (`proxy:write`, `proxy:delete` for deletes); router tests, golden lines;
   SDK `createRoute`, `updateRoute`, `deleteRoute`, `createPool`,
   `updatePool`, `deletePool`, `reloadConfig` with vitest.
3. **UI.** `useProxy()` hook on `client.proxy` (vitest); the proxy page
   (routes, pools, status, zone matrix; create/edit/delete/reload controls)
   with each control in `<Gated op="METHOD /api/v1/proxy/...">`; page
   vitest; test/integration/web/proxy.spec.ts; matrix rows and summary to
   `covered`.

## Out of scope

- Changes to the daemon REST (pkg/api/rest/proxy_handlers.go) or the proxy
  gRPC service.
- A `make web-e2e` target and a real-server Playwright run (the harness
  auth fixture sets a mock JWT).
