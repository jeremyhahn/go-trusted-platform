# #1831: unit tests for the kms dashboard pages

Part of UI epic #1665. Web only, no Go change.

## Objective

Every export of these three modules has a unit test (vitest), covering
normal, edge, error and invalid inputs:

- `web/src/app/(dashboard)/kms/[id]/page.tsx`: `generateStaticParams`, `Page`
- `web/src/app/(dashboard)/kms/encrypt/page.tsx`: `EncryptPage`
- `web/src/app/(dashboard)/kms/page.tsx`: `KMSKeysPage`

## Slices

1. `kms/[id]/page.test.tsx`: the placeholder static param; `Page` hands the
   same params promise (resolved, empty id, rejecting) to the client.
2. `kms/encrypt/page.test.tsx`: renders, encrypt and decrypt success paths,
   API error, empty or invalid input.
3. `kms/page.test.tsx`: key list loading, list render, empty list, API error.

A test that exposes a real bug gets a separate `fix(web)` commit after it.

## Out of scope

- `key-detail-client.tsx` (its own row).
- Any change to the modules beyond a bug a test exposes.
