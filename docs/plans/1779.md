# Plan: JS SDK CA service unit tests (#1779)

Part of the UI epic #1665.

## Objective

Every public method of `sdk/javascript/src/services/ca-service.ts` gets a
unit test with a mocked transport that asserts the HTTP method, path, query,
body and headers, plus one error case per method.

## Slices

1. `test(sdk)`: `sdk/javascript/src/services/ca-service.test.ts` with one
   `describe` and an `it.todo` per public method (16 methods).
2. `test(sdk)`: fill the tests: getInfo, getRootCertificate,
   listCertificates (query), getCertificate (path encoding),
   issueCertificate, revokeCertificate, renewCertificate (body mapping),
   verifyCertificate, getCRL, downloadCRL (Accept header), getBundle,
   downloadBundle, downloadCertificatePEM, downloadCertificateDER,
   getCertificateChain, isRevoked; each with an error case where the
   transport rejects and the error propagates.
3. `fix(sdk)` only if a test exposes a real bug in `ca-service.ts`.

## Out of scope

- Other SDK services, Go code, the UI.
- The pre-existing tsc errors in `src/services/quicbaas/__tests__` and
  `attestation-service.test.ts`.
