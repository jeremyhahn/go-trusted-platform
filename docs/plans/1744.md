# Plan: #1744 UI IAM groups, group members, permission check and tenants (slice 16 of #1665)

## Objective
Every IAM group, group member, permission check and tenant operation of the
REST API is reachable from a dashboard page and covered by a Playwright test
with mocked API responses.

Operations: CreateGroup, GetGroup, UpdateGroup, AddGroupMember,
RemoveGroupMember, CheckPermission, CreateTenant, GetTenant, ListTenants,
UpdateTenant, DeleteTenant.

## Slices, in order
1. `test(web)`: `web/e2e/iam-groups-tenants.spec.ts` with one `test.fixme`
   per operation.
2. `feat(sdk)`: the missing group, member, permission check and tenant
   methods in `sdk/javascript/src/services/iam-service.ts`, with vitest cases.
3. `feat(web)`: `web/src/app/(dashboard)/iam/tenants/page.tsx` (list, create,
   view, update, delete behind a confirm dialog), a hook in `web/src/hooks/`,
   a nav entry; group pages extended for update and members.
4. `test(web)`: the spec filled, one passing test per operation.

## Out of scope
- Tokens (CreateToken, RevokeToken, VerifyToken): no REST route.
- Policy and app pages (slice 17, #1728).
- Any Go change.
