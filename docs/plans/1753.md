# Plan #1753: invitation detail, lookup by token and accept flow (slice 19 of #1665)

## Objective
Every invitation read/accept operation of the backend is reachable from a web page
and exercised by a Playwright e2e test with mocked API responses:

- GetInvitation (`GET /invitations/{id}`)
- GetInvitationByToken (`GET /invitations/token/{token}`)
- AcceptInvitation (`POST /invitations/accept`)

## Slices
1. `test(web)`: `web/e2e/invitation-accept.spec.ts` skeleton, one `test.fixme` per operation.
2. `feat(sdk)`: missing methods on `InvitationService` in `sdk/javascript`, with vitest cases.
3. `feat(web)`: hook in `web/src/hooks/`, public accept page for a token (accept behind a
   confirm dialog), invitation detail reachable from the admin invitations list;
   spec filled so each operation has a passing test.

## Out of scope
- Go changes, backend routes, invitation create/revoke/resend (other slices).
