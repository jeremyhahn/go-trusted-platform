# #1824: unit tests for the TPM dashboard pages (UI epic #1665)

## Objective

Six TPM dashboard pages have no unit test. Add one `page.test.tsx` beside each
page, following `tpm/quote/page.test.tsx`: stub `useTPM` and `useToast` from
`@/hooks`, keep the real `useApi`, and drive each page through its UI.

## Slices (one commit each)

1. `tpm/eventlog`: parsed entries, PCR labels, dashes for missing fields, the
   200-row cap, the raw-log download, the empty state, server and thrown
   errors, Refresh.
2. `tpm/keys`: key list rendering, empty and error states, its actions.
3. `tpm/lockout`: lockout status, the reset action and its error path.
4. `tpm/nvram`: index list, read/write/define actions, invalid input.
5. `tpm/pcrs`: bank and PCR rendering, bank switch, error state.
6. `tpm/seal`: seal and unseal, empty and invalid input, error path.

A real bug a test exposes gets a separate `fix(web)` commit after the test.

## Gates

`npm run test:unit`, `npm run typecheck`, `npm run lint` in `web`; failures
also present on main are listed, not fixed.

## Out of scope

No change to the pages (unless a test exposes a bug), no Go change, the
`quote` and `status` pages (already tested).
