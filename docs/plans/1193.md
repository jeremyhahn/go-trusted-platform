# #1193 gateway-supervisor: sd_notify readiness and health

SPEC row `gateway-supervisor` (docs/SPEC.md): platformd as the single
supervisor, with restart with backoff and sd_notify-style readiness and
health. Design: `docs/gateway/supervisor.md` (NOTIFY_SOCKET per child).
#1714 landed the notify parser and socket (`process/notify.go`) but the
supervisor never binds one and still polls for readiness (#1697).

## Objective

Every supervised child gets its own pid-checked `AF_UNIX` `SOCK_DGRAM`
notify socket under the runtime directory, passed as `NOTIFY_SOCKET`, and
the supervisor takes readiness and health from it instead of polling.

## Slices, in order

1. Bind and pass the socket (this slice).
   - `launcher.go`: `Spec.NotifySocket`; `childEnv` drops any inherited
     `NOTIFY_SOCKET` and sets the child's own.
   - `supervisor.go`: `launch` binds `<RuntimeDir>/<process>.notify`
     (stale file removed), `SetPid` once launched, closes it on every
     failed launch, on `abandonLaunch` and in `clearProcessState`.
   - Tests: `TestChildEnv_SetsTheNotifySocket`,
     `TestChildEnv_DropsAnInheritedNotifySocket`,
     `TestSupervisor_LaunchPassesEachChildItsNotifySocket`,
     `TestSupervisor_StopRemovesTheNotifySocket`.
   - Readiness stays polled.
2. Done: the child sends `READY=1` through the socket once its hosted
   services start (a `STATUS=` line, never `READY=1`, when they fail) and
   `STOPPING=1` before it stops them; a failed send is logged, never fatal.
   - Tests: `TestServeProcess_NotifiesReadyOnceItsServicesStart`,
     `TestServeProcess_AFailedStartSendsNoReady`.
3. The supervisor awaits `READY=1` instead of polling, with the polled
   path kept as the fallback for a child that never notifies; tests for
   ready, timeout and a wrong-pid sender.
4. Health: `WATCHDOG=1` keepalives with a per-process interval; a missed
   interval restarts the child through the existing backoff; tests.

## Out of scope

- Restart backoff policy changes (already on main).
- Any change to the control-socket protocol or the desired document.
