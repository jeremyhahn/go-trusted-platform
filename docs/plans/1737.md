# Plan: #1737 UI device templates, profile assignment and config lookup

Slice 12 of the UI epic #1665 (coverage matrix of #1666).

## Objective

Every device template and profile-assignment operation is reachable from
`/devices/templates` and exercised by a Playwright test with mocked API
responses:

| Operation | Route | Reached by |
|---|---|---|
| CreateTemplate | `POST /device/templates` | Create Template dialog |
| GetTemplate | `GET /device/templates/{id}` | row menu, View Details dialog |
| UpdateTemplate | `PUT /device/templates/{id}` | row menu, Edit Template dialog |
| DeleteTemplate | `DELETE /device/templates/{id}` | row menu, Delete, confirm dialog |
| CreateProfileFromTemplate | `POST /device/templates/{id}/create-profile` | row menu, Create Profile dialog |
| FindConfigForDevice | `GET /device/profiles/find-config` | Profile Assignment panel, Find Config |
| AssignProfileToDevice | `POST /device/profiles/{id}/assign` | Profile Assignment panel, Assign Profile |
| UnassignProfileFromDevice | `POST /device/profiles/{id}/unassign` | Profile Assignment panel, Unassign, confirm dialog |

## Slices, in order

1. `web/e2e/device-templates.spec.ts`: one `test.fixme` per operation.
2. SDK: `DeviceService.unassignProfileFromDevice`; route-table vitest case.
3. Web: hook `useDeviceTemplateActions` (get, find-config, assign,
   unassign); `devices/templates/template-dialogs.tsx` (details, edit,
   create-profile and confirm dialogs, assignment panel); the templates page
   wires them and replaces `window.confirm` with the confirm dialog. The edit
   action no longer routes to the missing `/edit` page.
4. E2E: `mockDeviceTemplateApi` in `e2e/fixtures/api-mock.ts`; the spec
   fills every operation (plus a no-match find-config case).

5. Codex round 4: a Profile ID edit invalidates a pending Find Config, the
   unassign confirmation snapshots its target on open, and the error
   formatter reads a plain MutationError's message; vitest cases for each.

## Out of scope

- The template detail page (`templates/[id]`) still links to the missing
  `/edit` route; the dynamic page is not reachable under `next dev` with the
  static export, so it is left for a later slice.
- No Go change; the sidebar already lists Device Templates.
