# Plan: #1983, unix socket paths in tests exceed sun_path (main-fix)

## Objective

Main is red in FIPS shard 0: pkg/sdn/gateway/commands binds notify and
control sockets under t.TempDir(), and under the runner's long TMPDIR the
paths exceed the 108-byte sun_path limit. #1981 fixed four other packages
with a per-package `shortSocketDir(t)` helper; this lane applies it to
pkg/sdn/gateway/commands and to any package the sweep finds failing the
same way.

## Slices

1. pkg/sdn/gateway/commands: add shortsock_test.go (copy of the process
   package's helper), build the notify, routing, proxy and platformd socket
   paths under shortSocketDir(t). Test: with TMPDIR set to a 60-character
   directory, and without it, `go test ./pkg/sdn/gateway/commands/` passes.
2. Sweep with the same TMPDIR: pkg/daemon/commands, pkg/compute,
   pkg/cli/commands/device, pkg/cli/commands/tenant, pkg/cli, pkg/arch,
   internal/quicbaaskms, internal/xkms. Each package failing on a socket
   path length gets the same helper at its bind sites.

## Out of scope

- FIPS crypto/hmac short-key panics (#1979).
- pkg/qemu, pkg/swtpm (need QEMU or swtpm).
- .github/workflows, go.mod, go.sum, non-test code.
