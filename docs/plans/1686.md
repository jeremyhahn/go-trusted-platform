# Plan: #1686 platformctl attestation manifests list|get|delete

## Objective

Close the CLI gap named in `docs/attestation/architecture.md` ("Manifests,
quotes and policies still have no verb"): give attestation manifests a
`platformctl attestation manifests` verb group over the SDK calls that already
exist (`ListManifests`, `GetManifest`, `DeleteManifest` in
`sdk/go/services/attestation/client.go`). No API beyond the pinned lower
releases is needed, so go.mod is unchanged.

## Slices

1. Tests first (`pkg/cli/commands/attestation/manifests_test.go`), against a
   fake `AttestationServiceClient`:
   - `TestManifestsList_Table`: rows carry id, host, timestamp, VM and
     container counts; the host filter and limit reach the request.
   - `TestManifestsGet_JSON`: the manifest's wire shape is printed unchanged.
   - `TestManifestsDelete_Success`: the id reaches the RPC; the table output
     confirms the deletion.
   - `TestManifests_SDKError`: list, get and delete wrap an SDK failure in the
     typed errors `ErrListManifestsFailed`, `ErrGetManifestFailed`,
     `ErrDeleteManifestFailed` and print nothing.
2. The change: `manifests.go` (list with `--host-id`, `--limit`, `--offset`;
   `get <id>`; `delete <id>`), typed errors in `errors.go`, registration in
   `attestation.go`. `TestNewCommand_Surface` in `attestation_test.go` lists
   the subcommand names, so it gains `manifests`.
3. Docs: `docs/attestation/cli.md` §1 and §6 name the new verbs.
4. Codex rounds 1-5 (transport fixes the verbs exposed):
   - Manifest list time bounds: the filter keeps whole seconds, so REST
     answers 400 and gRPC/MCP InvalidArgument for a fractional
     `start_time`/`end_time` (tests: `..._ListManifestsFractionalTimeIs400`,
     `TestMCPManifestParity_ListRefusesFractionalTimeBound`).
   - QUIC get: host, VM and container evidence carry `timestamp_nanos`
     on the server and SDK wire (tests:
     `TestManifestNestedEvidenceKeepsNanoseconds`,
     `TestGetManifestOverQUIC`).

## Out of scope

- `build` and `verify` manifest verbs, quotes and policies verbs.
- Sub-second manifest list filtering (`ListManifestsFilter` stays in
  whole seconds; fractional bounds are refused instead).
- Integration (end-to-end) tests of the new verbs.
