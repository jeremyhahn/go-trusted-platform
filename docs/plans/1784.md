# Plan: JS SDK Compute service unit tests (#1784)

Objective: every public method of `sdk/javascript/src/services/compute-service.ts`
has a unit test with a mocked transport asserting HTTP method, path, query and
body, plus one error case per method.

Slices:
1. `src/services/compute-service.test.ts`: one `describe`, a stub per method.
2. Fill the tests (VM, disk, snapshot, container groups) on the mocked-transport
   pattern of the existing service tests; one rejection case per method.
3. A `fix(sdk)` commit only if a test exposes a real bug.

Out of scope: Go code, other SDK services, the wire-format test
(`__tests__/compute-service-wire.test.ts`) already on main.
