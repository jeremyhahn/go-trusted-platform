# Plan: unit tests for the networking components (#1815)

UI epic #1665 support. Web only; no Go change.

## Objective

Five modules in `web/src/components/features/networking` have no unit
test. Add one vitest + Testing Library test file per module, beside the
existing `gateway-snapshot-detail.test.tsx`, covering every export with
edge, error and invalid inputs.

## Slices (in order, one commit each)

1. `dns-record-form.test.tsx` — `DNSRecordForm`: add/edit titles, zod
   refusals (empty name/value, TTL range, SRV port range), the record sent
   per type (A, AAAA, CNAME, MX, TXT, NS, SRV), priority/weight/port
   defaulting to 0, edit sends old + new record, SOA/PTR not loaded,
   success and error toasts, loading state, Cancel.
2. `dns-record-table.test.tsx` — `DNSRecordTable`: empty state, row
   cells (TTL suffix, priority dash), Edit shown only with `onEdit`,
   Delete sends type and name, success refreshes, error toasts.
3. `dns-zone-table.test.tsx` — `DNSZoneTable`: empty state, row cells,
   created-at for valid, empty and invalid timestamps, View Records
   navigates, Delete success and error.
4. `gateway-routes-table.test.tsx` — `GatewayRoutesTable`: empty state,
   rate limit with and without window, auth and status badges, counters,
   Enable/Disable label, Edit only with `onEdit`, Delete and toggle
   refresh.
5. `sdn-topology.test.tsx` — `SDNTopology`: empty-state message, nodes
   per type, links with and without bandwidth, nodes without links.

The hooks (`@/hooks`) are faked in every file; Radix Select and
DropdownMenu are replaced with plain elements where jsdom cannot open
them.

## Out of scope

- Changing the modules (only a real bug a test exposes, as a separate
  `fix(web)` commit).
- The gateway route delete/toggle placeholders (no service method yet).
