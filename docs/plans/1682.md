# Plan: #1682 NTP status, sources and step page (epic #1665, slice 21)

## Objective
Make the NTP operations GetStatus, ListSources and Step reachable from the web UI,
backed by a JavaScript SDK service and exercised by a Playwright e2e spec.

## Slices (in order)
1. `web/e2e/ntp.spec.ts`: Playwright spec, one test per operation, with API
   responses mocked through `web/e2e/fixtures/api-mock.ts`.
2. `sdk/javascript/src/services/ntp-service.ts`: `getStatus` (`GET /status`),
   `listSources` (`GET /sources`), `step` (`POST /step`), shaped like
   `dns-service.ts`; exported from the services index; vitest case.
3. Web: a hook in `web/src/hooks/`, page
   `web/src/app/(dashboard)/networking/ntp/page.tsx` (status card, sources
   table, Step behind a confirm dialog) and a nav entry beside the other
   networking pages.

## Tests
- vitest: the SDK service calls the right method and path for each operation.
- Playwright: status card renders, sources table renders, Step confirm posts.
- Playwright: a failed sources read shows an error row; a failed status refresh
  after a good read marks the cached status Stale until the next good read.

## Out of scope
- Go changes (the backend operations exist).
- Other networking pages.
