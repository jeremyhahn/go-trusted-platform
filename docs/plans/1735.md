# Plan: #1735 UI TPM keys (slice 31 of #1665)

## Objective
Every TPM key lifecycle operation is reachable from the dashboard page
`/tpm/keys` and exercised by a Playwright test with mocked API responses:
Provision, Clear, GetCapabilities, GetPlatformAttributes, CreateEK,
ImportEKCertificate, DeleteEK, CreateSRK, DeleteSRK, CreateAK, GetAK,
DeleteAK, Quote, VerifyQuote, Certify.

## Slices
1. `web/e2e/tpm-keys.spec.ts`: one `test.describe`, a `test.fixme` per
   operation (test commit first, ruling 286).
2. SDK: the missing methods on `TpmService`
   (`sdk/javascript/src/services/tpm-service.ts`) with vitest cases.
3. Web: a hook in `web/src/hooks/` and the `/tpm/keys` page with a card per
   operation; Clear and Delete* behind a confirm dialog.
4. Fill the spec: each operation driven through the page with `page.route`
   mocks; the fixme markers go.

## Gates
`npm run typecheck`, `npm run lint`, `npm run test:unit` in `web/`;
`npx vitest run` and `npx tsc --noEmit` in `sdk/javascript`;
`npx playwright test e2e/tpm-keys.spec.ts --project=chromium`.

## Out of scope
PCR, credential, random and event log pages (slice 32, #1725). No Go change.
