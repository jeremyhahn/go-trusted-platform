# Plan: #1726 vTPM runtime UI (slice 35 of #1665)

## Objective
The web UI reaches every vTPM runtime operation of the REST API, each with a
Playwright e2e test on mocked API responses:
StartVTPM, StopVTPM, QuoteVTPM, SealVTPM, UnsealVTPM, ExtendVTPMPCR,
ReadVTPMPCR (`/bundles/{id}/...`). Running state comes from the start/stop
results (IsVTPMRunning has no REST route).

## Slices
1. `web/e2e/vtpm-runtime.spec.ts`: one `test.describe`, a `test.fixme` per
   operation (the test commit).
2. SDK: the missing methods in `sdk/javascript/src/services/vtpm-service.ts`
   with vitest cases.
3. Web: a hook in `web/src/hooks/`, the page
   `web/src/app/(dashboard)/tpm/vtpm/[id]/page.tsx` (stop and PCR extend
   behind a confirm dialog), a nav entry next to the TPM pages.
4. Fill the spec: every operation has a passing test with routes mocked
   through `web/e2e/fixtures/api-mock.ts`.

## Out of scope
- Bundles and templates pages (slice 34, #1674 / PR #1678).
- Any Go change.
