# Plan: #2009 enforce caller tenant on gRPC invitation create/list (SPEC row 125)

## Objective

`InvitationGRPCService.CreateInvitation` and `ListInvitations`
(pkg/api/daemon/invitation_grpc_service.go) pass `req.TenantId` to the
invitation service without comparing it to the caller's bound tenant, so a
tenant-A caller can create or list invitations in tenant B. Both methods must
refuse a cross-tenant request with `codes.PermissionDenied`, using the
existing `authorizeIAMTenant(ctx, req.TenantId)` check.

## Slices

1. `test(daemon)`: invitation_grpc_service_test.go cases where a tenant-A
   caller creating or listing (all and pending-only) invitations for tenant B
   gets PermissionDenied, and a same-tenant caller succeeds.
2. `fix(daemon)`: call `authorizeIAMTenant(ctx, req.TenantId)` after the nil
   request check in both methods.

Acceptance: `go test -count=1 -run Invitation ./pkg/api/daemon/...` passes.

## Out of scope

- Get/Revoke/Accept/Delete by ID or token (no tenant in the request).
- go.mod, go.sum, workflows, any other row.
