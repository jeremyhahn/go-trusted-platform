# Plan: JS SDK Invitation service unit tests (#1777, UI epic #1665)

## Objective

Pin every public method of `sdk/javascript/src/services/invitation-service.ts`
to its verb, path, query and body with a mocked transport, and check that a
transport error reaches the caller unchanged.

## Slices

1. `sdk/javascript/src/services/invitation-service.test.ts` (done):
   - `create`: POST `/v1/invitations` with the request body; error case.
   - `get`: GET `/v1/invitations/{id}`, id encoded as one segment; error case.
   - `getByToken`: GET `/v1/invitations/token/{token}`, token encoded; error case.
   - `list`: GET `/v1/invitations` with no query, with `page`, `limit`
     (from `pageSize`), `status` and `email`, and with unset filters left
     off; error case.
   - `revoke`: DELETE `/v1/invitations/{id}`; error case.
   - `accept`: POST `/v1/invitations/accept` with the request body; error case.
   - `resend`: POST `/v1/invitations/{id}/resend` with an empty body; error case.

## Out of scope

- Any change to `invitation-service.ts` (no test exposed a bug).
- Tests for the other JS SDK services without a unit test.
- The pre-existing `tsc --noEmit` errors in `src/services/quicbaas/__tests__`
  and `src/services/__tests__/attestation-service.test.ts` (same on main).
