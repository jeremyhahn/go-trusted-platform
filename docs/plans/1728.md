# Plan: #1728 UI IAM policy validate/test and app edit (slice 17 of #1665)

## Objective
Every IAM policy and app operation below is reachable from a dashboard page
and exercised by a Playwright e2e test with mocked API responses:
ValidatePolicy, TestPolicy, CreatePolicy, GetPolicy, UpdatePolicy, GetApp,
UpdateApp.

## Slices, in order
1. `web/e2e/iam-policies.spec.ts`: one `test.describe`, a `test.fixme` per
   operation (test commit first, ruling 286).
2. SDK: add the missing methods to `sdk/javascript/src/services/iam-service.ts`
   (validatePolicy, testPolicy and any of get/update policy and app that are
   missing) with vitest cases.
3. Web: `web/src/app/(dashboard)/iam/policies/test/page.tsx` (validate and
   test a policy document), a hook in `web/src/hooks/`, a nav entry; policy
   page gains an edit (PUT, behind a confirm dialog); app page gains an edit
   (PUT, behind a confirm dialog).
4. Fill the spec: every fixme becomes a passing test against
   `web/e2e/fixtures/api-mock.ts` mocks.

## Gates
`npm run typecheck`, `npm run lint`, `npm run test:unit` in `web/`;
`npx vitest run` and `npx tsc --noEmit` in `sdk/javascript`;
`npx playwright test e2e/iam-policies.spec.ts --project=chromium`.

## Out of scope
Go changes, other IAM resources (users, groups, roles, tokens), backend
behaviour.
