# Plan: #1736 UI BMC power, boot device, virtual media, sensors, provision (slice 2 of #1665)

## Objective
Every BMC operation below is reachable from a web page and exercised by a
Playwright test with mocked API responses:
PowerStatus, GetBootDevice, SetBootDevice, VirtualMediaStatus, MountISO,
UnmountISO, GetSensors, GetSystemInfo, Provision, ProvisionStatus,
GetWebCertificate (all under `/bmc/{profileID}/...`).

## Slices
1. `web/e2e/bmc-power.spec.ts`: one describe, a `test.fixme` per operation.
2. SDK: `sdk/javascript/src/services/bmc-service.ts` with the eleven methods,
   exported from the services index, with vitest cases per method.
3. Web: a hook in `web/src/hooks/` and the page
   `web/src/app/(dashboard)/devices/bmc/[profileID]/page.tsx`; the
   destructive actions (set boot device, mount, unmount, provision) sit
   behind a confirm dialog; a link to the page from the devices nav.
4. Fill the spec: one test per operation, mocks through
   `web/e2e/fixtures/api-mock.ts`.

## Out of scope
- Power on/off/reset/cycle (no REST route).
- Any Go change.
