# Plan #2028: PXE state persists in the deployment datastore

Part of SPEC row #1694 (split from PR #1896 by ruling 948). Builds on
#1896's daemon PXE backend wiring (off by default).

## Objective

docs/SPEC.md:23 puts platform state in the deployment datastore. The PXE
StateManager keeps devices in a `sync.Map`, so a daemon restart loses every
PXE device, its lifecycle state, retry count, events and IDevID binding.
After this row the StateManager writes every device change through to a
datastore-backed store and reloads it when the backend starts.

## Slices

1. `DeviceStore` seam in pkg/compute/pxe/state.go: interface
   `Put(ctx, *DeviceInfo)`, `Delete(ctx, id)`, `List(ctx)`; option
   `WithDeviceStore`; Register, Unregister, Transition and UpdateDevice write
   the new record before changing memory; `Load(ctx)` refills devices and byMAC.
   Test: pkg/compute/pxe/state_store_test.go restarts a StateManager over an
   in-memory fake store and finds the device in the same state, retry count,
   events and binding; Unregister also survives a restart.
2. Datastore-backed DeviceStore in pkg/storage/quicbaas/pxe_device.go,
   modelled on zone.go (DAO over Storage, system tenant). Test against the
   package's mock storage.
3. daemon.go passes `pxe.WithDeviceStore(...)` from the daemon's quicbaas
   storage and calls Load before Initialize. Daemon-level test: a completion
   report for a device enrolled before a restart succeeds.
   docs/provisioning/architecture.md gains a "Device store" section,
   which also records that a failed store write returns the error and
   leaves memory unchanged with no event emitted; multi-field operations
   (Authorize, Quarantine, UpdateDeviceState, Retry) commit in one
   TransitionWithUpdate, and a failed quarantine write keeps the
   quarantine flows (#2081 Codex).
4. Codex round 1 (#2081 P1): the pinned go-quicbaas v0.12.0-alpha embedded
   List ignores the page token and returns every record with a stale
   NextPageToken. `PXEDeviceStore.List` stops on a repeated token or a page
   larger than the page size, dedupes by ID and checks ctx each page. Tests
   fake the aggregated response, a repeated token, true paging and a
   cancelled context.

## Out of scope

- Migrating any other in-memory PXE state (VLAN allocations, sessions).
- Multi-daemon concurrency on one store (single writer per deployment).
- go.mod / go.sum changes.
