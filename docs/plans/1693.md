# Plan: #1693, export `ipxe.Lease`

## Objective

`ipxe.IPAllocator` cannot be implemented outside `pkg/ipxe` because
`GetLease` returns the unexported `*lease`. Export the type as `Lease`
(fields `IP`, `MAC`, `ExpiresAt`, already exported) so an external IPAM
integration can implement the interface and pass it to `WithIPAllocator`.

## Slices

1. Test: `pkg/ipxe/allocator_external_test.go` (`package ipxe_test`),
   `TestIPAllocator_ExternalImplementation`: a fake allocator compiles
   against `ipxe.IPAllocator`, is accepted by `ipxe.WithIPAllocator`, and
   `NewDHCPServer` returns it from `GetAllocator`.
2. Change: rename `lease` to `Lease` in `dhcp_server.go`, the interface and
   both implementations in `ipam_allocator.go`, and every test use.
3. Docs: `docs/ipxe/engineering.md` §2 and `docs/ipxe/api.md` no longer list
   the gap.

## Out of scope

- Any change to lease semantics, the lease tables or the IPAM seam.
- go.mod changes or lower-module bumps.
