# Epic #1665: the web UI supports every backend operation

## Objective

Every REST-routed backend operation has a page in the web dashboard and is
exercised by a Playwright e2e test with mocked API responses. The slices
come from the coverage matrix of the audit #1666.

## Slices

### Slice 13: EAB credentials (#1667)

- SDK: `EABService.markUsed(id)` (`POST /credentials/{id}/used`) and
  `EABService.cleanupExpired()` (`POST /credentials/cleanup`), with vitest
  cases for both.
- Hooks: the EAB hooks gain the two new calls.
- Pages: `ca/eab` (list, create, revoke, delete, validate, cleanup expired,
  lookup by key ID) and `ca/eab/[id]` (get, QR code, enrollment URL, mark
  used); a nav entry beside the other CA pages.
- Tests: `web/e2e/eab.spec.ts`, one test per operation, API mocked.

### Slice 18: IDevID and IAK (#1672)

- `web/e2e/idevid.spec.ts`: one test per operation (HasIDevID, HasIAK,
  GetDeviceAttributes, GenerateIAK, DeleteIAK, CreateIAKCSR, CreateLDevID,
  InstallIDevIDCertificate, InstallIAKCertificate, DeleteIAKCertificate,
  FlushTransientContexts, ActivateCredential).
- `web/src/app/(dashboard)/tpm/idevid/page.tsx`: status cards, IAK
  actions, certificate install/delete and maintenance; destructive actions
  behind a confirm dialog.
- An idevid hook in `web/src/hooks/` and a nav entry beside the TPM pages.
- SDK `idevid-service.ts`: only a method that is missing, with a vitest case.

## Out of scope

- Backend (Go) changes.
- Slices of other rows of the coverage matrix.
- Go backend changes.
- Redesign of existing pages.
- InitCA, InstallCACertificates, UninstallCACertificates (no REST route).
- Go changes.
- Go changes, backend API changes.
- Real-backend e2e (CI integration targets cover the API).
- Go changes, backend operations, and API contract changes.
- Restyling existing pages.
