# Epic #1665: the web UI supports every backend operation

## Objective
Every REST operation of the platform is reachable from a dashboard page and
exercised by a Playwright e2e test with mocked API responses
(`web/e2e/fixtures/api-mock.ts`). The coverage matrix of audit #1666
(`docs/ui/coverage-matrix.md`) lists the gaps; each slice closes one group.

## Slices (in order)
1-3. Earlier slices of the matrix (other lanes).
4. CA operations (#1668): GetCAInfo, SignCSR, VerifyCertificate.
   - Pages: `ca/page.tsx` (CA overview from `GET /v1/ca/info`),
     `ca/sign/page.tsx` (`POST /v1/ca/sign-csr`),
     `ca/verify/page.tsx` (verify a PEM certificate).
   - Tests: `web/e2e/ca-operations.spec.ts`, one test per operation;
     an SDK vitest case for `signCSR()` if the SDK lacked it.
   - Codex round 4: the server refuses sign-csr without a platform token
     holding `ca:sign-csr`. Test commit: the sign-csr mock refuses a
     request with no `Authorization: Bearer` header and the sign tests fill
     a "Platform token" field and assert the header. Fix commit: the sign
     page gains a required "Platform token" password input and signs
     through a per-call `createPlatformClient` carrying the Bearer header
     (CAService.signCSR takes no per-request headers); the token is part
     of the shown result's input key.

## Out of scope
- InitCA, InstallCACertificates, UninstallCACertificates (no REST route).
- Go changes.
