# Epic #1665: the web console against a real server

Ruling 972 (2026-11-19): every UI control is implemented and a Playwright
suite proves it works against the real platform daemon, not `api-mock.ts`.

## Objective

`make web-e2e` builds platformd with the embedded console, starts it on the
in-process TPM simulator with a throwaway data directory, and runs
`web/e2e/real-server/` in Chromium, logging in through real WebAuthn
ceremonies (Chromium's virtual authenticator, no cookie forging).

## Slices, in order

1. **#2034 slice A: harness, make target, auth port.**
   - `web/e2e/real-server/platformd.test.yaml`: web-test config with
     `tpm.simulator: true`, embedded in-memory quicbaas, TLS on 18443.
   - `global-setup.ts`: fresh temp dir, `platformd --init`, wait on
     `/health/ready`; `global-teardown.ts` stops it and removes the dir.
   - `web/playwright.real-server.config.ts`; Makefile `web-e2e`
     (`make build WITH_WEB=1`, then the suite).
   - `auth.spec.ts` ported: forms, protected-route redirects, register,
     log out, log in again, duplicate account, all against the server.
   - Status 11-20: harness and spec committed; `make web-e2e` not green.
     Blockers: (a) `next build` stops with `SecurityFatalError` (Next.js
     advisory check), so `make build WITH_WEB=1` fails at
     `_web-embed-prepare`; (b) on `make build`, platformd completes first
     boot on the simulator, then exits 1: `bootstrap secret resolution:
     ... unresolved secret reference remains after resolution`, and the
     log never names the field (secrets.go per-field lines absent).
     The browser is not installed by the target (the install hung).
   - 11-20 ui2034b: (b) fixed. The per-field lines go to
     `trusted-data/log/trusted-platform.log`, not stdout: both CA
     identities had no `keystores.software.password`, a protected field
     the fail-closed processor refuses empty. Added
     `kms://ca/{root,issuing}/software/password?ensure=true` in the test
     config and web-test.example.yaml; secrets now resolve. Three start
     blockers remain, none in config:
     (c) `make build` lacks the `tpm_simulator` tag ("TPM simulator not
     available"), and the simulator also needs CGO; `make build` hard-sets
     CGO_ENABLED=0. web-e2e needs its own CGO platformd build (Makefile).
     (d) with a CGO+tpm_simulator platformd, InitTPM exits: "ESP seal state
     is indeterminate — mount /boot/efi" (pkg/app/tpm_seal_guard.go
     probeTPMSealArtifacts; app.go InitTPM). No config skips the probe on
     the simulator: needs a Go change (owner decision: simulator bypass).
     (e) `make web-e2e WEB_E2E_BUILD=0` stops before global setup:
     `Cannot find module '@playwright/test'` (run `make web-deps` first).
2. **Slice B: real-auth fixtures + dashboard.** A fixture that registers
   (or reuses, via exported virtual-authenticator credentials) a seeded
   admin and one tenant; `dashboard.spec.ts` ported on it.
3. **Slices C..n: the other specs**, a few per slice, each control
   capability-gated and checked against the server's routes (audit #1666);
   gaps found go to the report, not mocks.
4. **CI job** running `make web-e2e` as a required check: a `.github`
