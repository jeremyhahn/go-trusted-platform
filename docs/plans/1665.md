# Plan: epic #1665 (UI epic), splits of #1675

## Split 1: UI epic Go backend (#1665), PR #2021

### Go backend objective

Land the UI epic's Go backend (daemon and REST: EAB, IDevID, SDN, tenant,
BMC, compute, vTPM, route registry) in PR #2021 and answer Codex's review
rounds on it.

### Go backend slices

1. Go backend (done, the PR's first commit).
2. Codex round 1 (this slice): a test commit, then a fix commit.
   - SDN ApplyPolicy: a failed update of an existing PolicyId re-installs
     the old policy's flows after the rollback deletes the replacements.
     Test: TestSDNService_ApplyPolicy_FailedUpdateRestoresTheActivePolicy.
   - compute FinalizeIncoming: a committed receiver is adopted as a
     normal instance (o.instances, lifecycle Running, wait goroutine), so
     Get, List, Stop and Close see it. Tests:
     TestFinalizeIncoming_CommitAdoptsTheGuest,
     TestFinalizeIncoming_FailedCommitAdoptsNothing.
   - compute receiver lifetime: receiverLifetime bounds idle preparation;
     an active migration stream (QMP query-migrate) renews it. Test:
     TestReceiveIncoming_ActiveTransferRenewsTheLifetime.

- Codex P1 on pkg/webservice/v1/rest/iam/adapter.go: Policy.Simulate is
  not registered by the pinned go-quicbaas embedded transport. It needs a
  go-quicbaas change and a tag bump; no go.mod change here.
