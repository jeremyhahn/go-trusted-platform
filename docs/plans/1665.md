# Epic #1665: the web UI supports every backend operation

Objective: every backend operation listed in the coverage matrix of #1666
(`docs/ui/coverage-matrix.md`) is reachable from a web page and exercised by a
Playwright e2e spec with mocked API responses (`web/e2e/fixtures/api-mock.ts`).

## Slices (one lane each, in order of the matrix)

- Slice 19 (#1671): invitations.
  - GetInvitation: `web/src/app/(dashboard)/tenant/invitations/[id]/page.tsx`.
  - GetInvitationByToken, AcceptInvitation:
    `web/src/app/(auth)/invite/[token]/page.tsx`.
  - SDK: `sdk/javascript/src/services/invitation-service.ts` gains any missing
    method, with a vitest case.
  - Tests: `web/e2e/invitation-accept.spec.ts`, one test per operation.
- Codex round 2 on #1681: the invite page no longer calls AcceptInvitation
  (it consumes the invitation without joining the tenant); signed-out
  visitors get the passkey sign-up (RegisterInvitedUser joins them), signed-in
  sessions (login name in user_id/sub) get a notice, not a dead end. Tests:
  `invite-accept-client.test.tsx` and the e2e spec. Joining an existing
  account from an invitation needs a server operation: out of scope.
- Other slices: added here by the lane that takes them.

## Gates per slice

`npm run typecheck`, `npm run lint`, `npm run test:unit` in `web/`; the new
spec under `npx playwright test <spec> --project=chromium`; `npx vitest run`
and `npx tsc --noEmit` in `sdk/javascript` when the SDK changes.

## Out of scope

- Go changes, backend operations, and API contract changes.
- Restyling existing pages.
