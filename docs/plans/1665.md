# Epic #1665: web UI covers every backend operation

## Objective
Every backend operation listed in the #1666 coverage matrix is reachable from a
web page and exercised by a Playwright e2e test with mocked API responses.

## Slices (in order)
1. Slice 30 (#1673): tenant lifecycle, quota and DEK.
   - `web/e2e/tenant-admin.spec.ts`: one test per operation (ListTenants,
     CreateTenant, GetTenantByName, DeleteTenant, UpdateTenant, SuspendTenant,
     ResumeTenant, UpdateQuotas, CheckQuota, Sync, RotateTenantDEK,
     GetTenantDEKStatus, InitTenantBarrier, UnsealTenantBarrier,
     SealTenantBarrier).
   - `web/src/app/admin/tenants/page.tsx` (list, create, search, delete) and
     `web/src/app/admin/tenants/[id]/page.tsx` (update, lifecycle, quotas,
     sync, DEK, barrier); destructive actions behind a confirm dialog.
   - SDK methods missing from `tenant-service.ts`, each with a vitest case.
2. Later slices: the remaining rows of the coverage matrix, one service each.

## Out of scope
- Go changes; backend behaviour; visual redesign of existing pages.
