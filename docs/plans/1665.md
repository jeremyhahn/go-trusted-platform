# Epic #1665: the web UI supports every backend operation

Objective: every backend operation is reachable from a dashboard page and
exercised by a Playwright e2e test with mocked API responses
(`web/e2e/fixtures/api-mock.ts`). Slices follow the coverage matrix of #1666.

## Slices (in order)

1. Slice 34 (#1674): vTPM bundles and templates.
   - Pages: `vtpm/templates` (ListTemplates, CreateTemplate, GetTemplate,
     CloneTemplate, DeleteTemplate behind a confirm dialog), `vtpm/bundles`
     (list + ImportBundle), `vtpm/bundles/[id]` (GetBundle, ValidateBundle,
     GetBundlePath, GetTPMSocketPath, GetNVRAMPath).
   - Tests: `web/e2e/vtpm.spec.ts`, one test per operation; a vitest case
     for any SDK method added to `vtpm-service.ts`.

Later slices are added by the lanes that build them.

## Out of scope

- Go changes, backend API changes.
- Real-backend e2e (CI integration targets cover the API).
