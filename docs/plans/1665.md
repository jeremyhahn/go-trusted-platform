# Plan: epic #1665 (UI epic), splits of #1675

## Split 1: UI epic Go backend (#1665), PR #2021

### Go backend objective

Land the UI epic's Go backend (daemon and REST: EAB, IDevID, SDN, tenant,
BMC, compute, vTPM, route registry) in PR #2021 and answer Codex's review
rounds on it.

### Go backend slices

1. Go backend (done, the PR's first commit).
2. Codex round 1 (this slice): a test commit, then a fix commit.
   - SDN ApplyPolicy: a failed update of an existing PolicyId re-installs
     the old policy's flows after the rollback deletes the replacements.
     Test: TestSDNService_ApplyPolicy_FailedUpdateRestoresTheActivePolicy.
   - compute FinalizeIncoming: a committed receiver is adopted as a
     normal instance (o.instances, lifecycle Running, wait goroutine), so
     Get, List, Stop and Close see it. Tests:
     TestFinalizeIncoming_CommitAdoptsTheGuest,
     TestFinalizeIncoming_FailedCommitAdoptsNothing.
   - compute receiver lifetime: receiverLifetime bounds idle preparation;
     an active migration stream (QMP query-migrate) renews it. Test:
     TestReceiveIncoming_ActiveTransferRenewsTheLifetime.

### Go backend out of scope

- Codex P1 on pkg/webservice/v1/rest/iam/adapter.go: Policy.Simulate is
  not registered by the pinned go-quicbaas embedded transport. It needs a
  go-quicbaas change and a tag bump; no go.mod change here.

## Split 2: JS SDK, PR #2022

### JS SDK objective

Ship the JS SDK services, types and React hooks for the UI epic endpoints
under sdk/javascript, with test suites that match the current contracts.

### JS SDK slices (in order)

1. feat(sdk/js): services, types and hooks for the UI epic endpoints (done).
2. Codex round 1 on #2022:
   - test: finalizeMigration passes `{ retry: { enabled: false } }` and a lost
     response after commit is surfaced once, never resent.
   - fix: finalizeMigration disables client retries (the daemon drops the
     receiver token before commit, so a resend answers 404).
   - fix: test suites follow the source contracts: string EAB ids, `/url`,
     offset (not page) for tenants and vTPM bundles, full prototype case
     lists for Compute, TPM and IDevID, `userId` on invitation accept, and
     the eight useEAB mutations (markUsed, cleanupExpired tested).
3. Codex round 5 on #2022 (LDevID wire contract):
   - createLDevID sends the CSRTemplate and its TCGDeviceAttributes with
     the snake_case json tags of sdk/go/gen/idevid.pb.go (the daemon uses
     encoding/json; protojson in the webservice accepts them too).
   - the response's nested `certificate` (DeviceIdentityCertificate) is
     normalised to camelCase, with `{seconds, nanos}` timestamps as ISO
     strings; a camelCase webservice body passes through unchanged.

### JS SDK gates

`make web-deps`, then in sdk/javascript `npm test` and `npm run typecheck`.

### JS SDK out of scope

Service source changes beyond finalizeMigration's retry option; web lint
(#419); the other #1675 splits.
