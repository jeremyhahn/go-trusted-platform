# #2037 part 3: real-server e2e ports (epic #1665, ruling 972)

## Objective

Port this part's mocked Playwright specs to the real-server harness
(`web/playwright.real-server.config.ts`, testDir `web/e2e/real-server`):
import only `./fixtures` and `@playwright/test`, seed through the `sdk`
fixture, assert on server state. Each port deletes the mocked spec it
replaces in the same commit. Mocked cases with no server behaviour behind
them are listed below as gaps for the route audit; none is dropped silently.

## Slices

1. Done: tenant-isolation, tenant-management, tenant (now
   `tenant-port.spec.ts`), tpm-attestation, tpm-ops, vpn (now
   `vpn-port.spec.ts`) and vtpm-runtime.
2. Rename the two ports whose names other UI rows also add; this file takes
   the part's gaps out of the shared `docs/plans/1665.md`.
3. Merge `row/1665-ui-e2e-auth` (the harness fixtures).
4. One commit per spec: platform-services, sdn-ports, switch-ports,
   tenant-admin, tenant-lifecycle, tpm-keys, vtpm, devices.

## Gaps

### Slice 1 specs

Forged JWT role/claim sessions, second-tenant switching, injected 500,
network and fetch errors with Retry, delayed-loading states, empty states,
expired/accepted/draft/archived forged statuses, TPM-unavailable and forged
TPM properties, seal/unseal and build error injection, SHA-1 and copy-PCR,
MakeCredential/ActivateCredential canned AK, extend request-body recording,
VPN gateway status card (sessions, refusals, events, leases), cross-tenant
enrolment, vTPM late replies, start/stop serialization and the
daemon-listener /pcr/{index} variant.

### platform-services

- ListServices error card: the mocked 500 ("service manager down") has no
  server behaviour behind it; the real daemon answers the list.
- Service actions run on one listed service (ntp, dns, pxe or vpn first)
  and start it again afterwards; the mocked fixed versions, commits and
  uptimes are replaced by what the daemon returns.

### sdn-ports

- Canned port counters (1234 received, 4500 sent, 7 dropped) and policy
  hit count 42: the port asserts the counter labels the server fills.
- AuthenticatePort with a certificate the harness issued: the port sends
  an unissued PEM and asserts the server's answer (toast only on success).
- RevokePortAuth of an authenticated port: needs the case above.
- No DeletePolicy route in the SDK: policies a test creates are disabled
  through ApplyPolicy afterwards, not deleted.

## Acceptance

specs, `npx playwright test --config playwright.real-server.config.ts
--list`; no go.mod, go.sum or package-lock.json change.

Harness files, `docs/plans/1665.md`, the mocked fixtures in
